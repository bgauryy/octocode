# Octocode user guides

Octocode gives you one set of research tools in two forms: a terminal CLI and an MCP server for your coding agent. [Install Octocode and try a local read](../README.md#install)

| I want to… | Open |
|---|---|
| Connect my agent or troubleshoot MCP startup | [MCP server](OCTOCODE_MCP.md) |
| Run a tool from the terminal or a script | [CLI](OCTOCODE_CLI.md) |
| Sign in to GitHub or use GitHub Enterprise | [Authentication](AUTHENTICATION.md) |
| Change a default, set a key or enable an optional tool | [Configuration](CONFIGURATION.md) |
| Choose among local, GitHub, package and classification tools | [Tool reference](OCTOCODE_TOOLS.md) |
| See how an agent goes from a question to source evidence | [Research workflows](OCTOCODE_PROTOCOL.md) |
| Build a code graph and read importers, hubs, impact or co-change | [Code graph](OCTOCODE_GRAPH.md) |
| Select relevant results or ask questions about unread files | [Classification](OCTOCODE_CLASIFY.md) |
| Follow a cursor or interpret a partial result | [Tool data and continuations](TOOL_DATA_CONTRACT.md) |
| Find cached data, change storage or clear saved results | [Storage and limits](STORAGE_AND_LIMITS.md) |
| Check which files Octocode can read and what leaves my machine | [Security](SECURITY.md) and [privacy](../PRIVACY.md) |
