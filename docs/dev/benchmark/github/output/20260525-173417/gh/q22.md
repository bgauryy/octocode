In `sveltejs/svelte`, find where `$state` values are represented as reactive signals at runtime. What is the core primitive and how is state mutation tracked?

## Answer

- In `sveltejs/svelte`, `$state` values are represented as **signals** at runtime using the `source()` / `state()` function in `packages/svelte/src/internal/client/reactivity/sources.js`
- The core primitive is a **`Source` object** (a signal) with the shape: `{ f: flags, v: value, reactions: null, equals, rv: readVersion, wv: writeVersion }`
- The `state(v)` function wraps `source(v)` and registers it with the component context via `push_reaction_value()`
- State mutation is tracked via the `set(source, value)` function: it increments `write_version` via `increment_write_version()`, updates `source.v`, then calls `update_effect()` to notify all `reactions` (effects/deriveds) subscribed to this source that they are dirty
- Reading a source inside an effect/derived registers the current `active_reaction` into the source's `reactions` list (pull-based subscription), creating the dependency graph at read time
