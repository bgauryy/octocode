## Answer

- **vercel/next.js**: Server render function is in `packages/next/src/server/app-render/stream-ops.web.ts` via `continueFizzStream()`; calls `renderToReadableStream` from `react-dom/server` (imported at line 10); also `packages/next/src/server/render.tsx` for Pages Router
- **remix-run/react-router**: Server render function is `ServerRouter` in `packages/react-router/lib/dom/ssr/server.tsx`; the framework uses `renderToReadableStream` or `renderToString` from React in the user-supplied `entry.server.tsx` (framework does not call it directly, delegates to user)
- **nuxt/nuxt**: Server render function is `renderRoute()` in `packages/nitro-server/src/runtime/handlers/renderer.ts`; calls `renderer.renderToString(ssrContext)` using Vue's `@vue/server-renderer` SSR renderer
