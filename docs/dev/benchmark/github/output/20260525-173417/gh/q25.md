## Answer

- `packages/vite/src/node/` is the main server subsystem with the following key areas:
- **`server/`** — Dev server: `index.ts` (ViteDevServer creation), `moduleGraph.ts` (module dependency graph), `hmr.ts` (Hot Module Replacement), `pluginContainer.ts` (Rollup-compatible plugin pipeline), `transformRequest.ts` (on-demand file transform), `ws.ts` (WebSocket for HMR), `middlewares/` (Connect middleware chain)
- **`plugins/`** — Built-in transform plugins: `resolve.ts` (module resolution), `css.ts` (CSS processing), `html.ts` (HTML transform), `importAnalysis.ts` (import rewriting/analysis for dev), `importAnalysisBuild.ts` (import analysis for build), `esbuild.ts` (TypeScript/JSX via esbuild), `asset.ts` (static asset handling), `json.ts`, `wasm.ts`, `worker.ts`, `define.ts` (global replacements), `manifest.ts`
- **`optimizer/`** — Dependency pre-bundling: bundles `node_modules` with esbuild for faster dev server startup and CJS→ESM conversion
- **`ssr/`** — SSR module loading: separate module runner for server-side code execution
- **`build.ts`** — Production build orchestration via Rollup
- **`config.ts`** — Config loading and resolution (`defineConfig`)
- **`module-runner/`** — Module runner for Vite's server-side module execution environment
- **`client/`** — Browser client runtime (HMR client, overlay)
- **`shared/`** — Utilities shared between client and server
