### Q32 — Where is `parse()` implemented in Zod v4?

Find where `parse` is defined in `colinhacks/zod` (v4 core). What internal method does it call to validate, and what happens when the validation result is a Promise?

## Answer

- `parse` for Zod v4 core is implemented in `colinhacks/zod` at `packages/zod/src/v4/core/parse.ts`.
- The exported `parse` is `export const parse: $Parse = _parse(errors.$ZodRealError)`; `_parse` returns the actual `(schema, value, _ctx, _params)` parser.
- `_parse` creates a synchronous parse context (`async: false`) and validates by calling the schema internals: `schema._zod.run({ value, issues: [] }, ctx)`.
- If `schema._zod.run(...)` returns a `Promise`, synchronous `parse` throws `new core.$ZodAsyncError()` instead of awaiting it; callers must use `parseAsync`.
- If the non-promise result has issues, it builds a `Zod` error from `result.issues.map((iss) => util.finalizeIssue(...))`, captures the stack with `util.captureStackTrace`, and throws it; otherwise it returns `result.value`.
