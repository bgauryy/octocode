## Answer

- **Next.js file that calls `renderToReadableStream`**: `packages/next/src/server/app-render/stream-ops.web.ts`
- It imports `renderToReadableStream` directly from `'react-dom/server'` (line 10), and calls it via `renderToInitialFizzStream({ ReactDOMServer: { renderToReadableStream }, element, streamOptions })` inside `renderToWebFizzStream()`
- **React file that defines `renderToReadableStream`**: `packages/react-dom/src/server/ReactDOMFizzServerEdge.js` (Edge/browser runtime); also `ReactDOMFizzServerBun.js` (Bun) and `ReactDOMFizzServerNode.js` (Node.js)
- The `react-dom/server` entry point (`packages/react-dom/npm/server.edge.js`) re-exports the built CJS bundle `react-dom-server.edge.production.js` which is compiled from `ReactDOMFizzServerEdge.js`
