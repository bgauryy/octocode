## Answer

- **app-render/**: App Router rendering pipeline (RSC, streaming, PPR, Fizz streams)
- **route-modules/**: Route module types (app-page, app-route, pages, pages-api)
- **route-definitions/**, **route-matchers/**, **route-matcher-managers/**, **route-matcher-providers/**: Routing subsystem — definitions, matching, and provider abstractions
- **async-storage/**: AsyncLocalStorage-based request/work context stores
- **lib/**: Shared server utilities (tracing, app-dir modules, cache handling)
- **api-utils/**: API route utilities (Node.js and Edge)
- **dev/**: Dev server tools (hot reload, webpack overlay)
- **base-http/**: Abstraction layer over Node.js/Edge HTTP request/response
- **web/**: Edge runtime server adapter
- **response-cache/**: Response caching layer
- **resume-data-cache/**: PPR resume data caching
- **stream-utils/**: Stream transformation helpers
- **use-cache/**: `use cache` directive implementation
- **after/**: `after()` API implementation
- **instrumentation/**: OpenTelemetry instrumentation hooks
- **og/**: Open Graph image generation
- **mcp/**: MCP (Model Context Protocol) integration
- **normalizers/**: URL/path normalization utilities
- **typescript/**: TypeScript language service plugin
- Notable files: `base-server.ts` (base server class), `next-server.ts` (production server), `render.tsx` (Pages Router renderer), `config.ts`/`config-schema.ts` (Next.js configuration)
