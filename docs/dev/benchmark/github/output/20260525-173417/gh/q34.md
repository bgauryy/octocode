## Answer

- `initTRPC` is `export const initTRPC = new TRPCBuilder()` in `packages/server/src/unstable-core-do-not-import/initTRPC.ts`.
- `TRPCBuilder` exposes three fluent methods: `.context<TNewContext extends object | ContextCallback>()`, `.meta<TNewMeta extends object>()`, and `.create<TOptions extends RuntimeConfigOptions<TContext, TMeta>>(opts?)`.
- `.context()` returns a new `TRPCBuilder` with the context generic replaced by either the object type or the unwrapped return type of a context callback; `.meta()` returns a new `TRPCBuilder<TContext, TNewMeta>`.
- `.create()` builds a `RootConfig` from options: resolved `transformer` via `getDataTransformer`, `isDev`, `allowOutsideOfServer`, `errorFormatter`, `isServer`, and internal `$types`.
- It performs a server-environment guard: if not server and `allowOutsideOfServer !== true`, it throws `You're trying to use @trpc/server in a non-server environment...`.
- `.create()` returns a `TRPCRootObject` with these properties: `_config`, `procedure`, `middleware`, `router`, `mergeRouters`, and `createCallerFactory`.
- The returned `procedure` is `createBuilder({ meta: opts?.defaultMeta })`; `middleware` is `createMiddlewareFactory()`, `router` is `createRouterFactory(config)`, `mergeRouters` is the imported merge helper, and `createCallerFactory` is `createCallerFactory<$Root>()`.
