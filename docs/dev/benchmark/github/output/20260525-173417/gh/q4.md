## Answer

- Yes, Next.js App Router uses React's `startTransition` in client code
- Primary usage is in `packages/next/src/client/components/app-router.tsx`
- First usage: wraps `dispatchAppRouterAction({ type: ACTION_RESTORE, ... })` — dispatches a route restore action when external history changes (pushState/replaceState patches) are detected
- Second usage: wraps `dispatchTraverseAction(...)` — handles browser back/forward button navigation (popstate events)
- `startTransition` is also used in `packages/next/src/client/components/redirect-boundary.tsx`, `app-call-server.ts`, `form.tsx`, and other client components
