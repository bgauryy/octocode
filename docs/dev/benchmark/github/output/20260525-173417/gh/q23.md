### Q23 — Vue 3 template compiler: `v-if`

In `vuejs/core`, find the function that processes `v-if` / `v-else-if` / `v-else` during template compilation. What AST node does it produce?

## Answer

- The function is `transformIf` in `packages/compiler-core/src/transforms/vIf.ts`
- It is created via `createStructuralDirectiveTransform(/^(?:if|else|else-if)$/, ...)` — handles `v-if`, `v-else-if`, and `v-else`
- The core logic is in `processIf()` (also in the same file)
- For `v-if` / `v-else-if`: it produces an **`IfNode`** AST node (`type: NodeTypes.IF`) with a `branches` array of `IfBranchNode` objects (`type: NodeTypes.IF_BRANCH`)
- Each `IfBranchNode` contains the branch `condition` expression and its `children`
- The codegen output uses `createConditionalExpression()` to generate a ternary expression (`condition ? branch : fallback`)
- `v-else-if` and `v-else` are appended as additional branches to the existing `IfNode` from the preceding `v-if` sibling
