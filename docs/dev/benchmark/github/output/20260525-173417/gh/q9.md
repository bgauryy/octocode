## Answer

- `packages/` — the main Next.js npm packages (next, create-next-app, etc.)
- `apps/` — internal test/demo applications used in CI
- `bench/` — benchmarking infrastructure
- `crates/` — Rust/WebAssembly code (SWC/Turbopack Rust crates)
- `docs/` — public documentation
- `errors/` — error message documentation pages
- `examples/` — example Next.js projects demonstrating various integrations
- `evals/` — AI/model evaluation scripts
- `scripts/` — build, release, and CI utility scripts
- `test/` — integration and e2e test suite
- `turbopack/` — Turbopack bundler source code
- `turbo/` — Turborepo pipeline configuration
- `rspack/` — Rspack bundler integration code
- `contributing/` — contributor guides and docs
- `patches/` — dependency patches (patch-package)
