Find the core navigation primitive in `vercel/next.js`, `remix-run/react-router`, and `TanStack/router`.

## Answer

- **vercel/next.js**: core navigation primitive is `router.push()` defined in `packages/next/src/shared/lib/router/router.ts`; it calls `this.change('pushState', url, as, options)` internally using `window.history.pushState`
- **remix-run/react-router**: core navigation primitive is `router.navigate()` defined in `packages/react-router/lib/router/router.ts`; accepts `To | null` with `RouterNavigateOptions`
- **TanStack/router**: core navigation primitive is `useNavigate()` hook defined in `packages/router-core/src/useNavigate.ts`; returns a function accepting `NavigateOptions` that returns `Promise<void>`
