## Answer

- **Problem solved**: Exposes the `attach` function from `react-devtools-inline` to support the "Reload & Profile" feature in embedded DevTools setups (e.g., web extensions) where the frontend and backend run in separate contexts and the page cannot be reloaded
- **Files changed**: `packages/react-devtools-inline/src/backend.js` (+23 lines, exports `attach`); `packages/react-devtools-inline/src/frontend.js` (+6 lines, adds reload callback); `packages/react-devtools-shared/src/devtools/index.js` (removed, -21 lines); `packages/react-devtools-shared/src/devtools/store.js` (+1 line); `packages/react-devtools-shell/src/app/devtools.js` (refactored, +15/-21 lines)
- **Core technical disagreement**: Reviewer `hoxyq` preferred using `__REACT_DEVTOOLS_ATTACH__` global + controlling the full reload flow within `react-devtools-inline` rather than directly exporting `attach`; also wanted the PR to not change `react-devtools-shell` and to avoid adding a `reload` callback to the frontend
- **Why not merged**: `react-devtools-inline` is deprioritized by Meta maintainers (`hoxyq` had no bandwidth); the package may be deprecated or moved; the PR was auto-closed as stale twice and reopened; the design disagreement was never resolved
