## Answer

- `Context` is defined in `honojs/hono` at `src/context.ts` as `export class Context<E extends Env = any, P extends string = any, I extends Input = {}>`.
- The generics mean: `E` is the Hono environment/bindings/variables type, `P` is the route path parameter string type, and `I` is the typed input object; `req` is exposed as `HonoRequest<P, I['out']>`.
- Important context properties/getters include `env: E['Bindings']`, `error`, `finalized`, `req`, `event`, `executionCtx`, `res`, `var`, plus mutable helpers `set()`, `get()`, `header()`, and `status()`.
- Core response construction is `#newResponse(data, arg, headers)` and public `newResponse`, which merges existing/prepared headers, explicit headers, status from `arg` or `this.#status`, and returns a `Response`.
- Response helper methods exposed by `Context` include `body(data, arg?, headers?)`, `text(text, arg?, headers?)`, `json(object, arg?, headers?)`, `html(html, arg?, headers?)`, `redirect(location, status?)`, and `notFound()`.
- `body()` returns a raw body response via `#newResponse`.
- `text()` sets default `Content-Type` to `text/plain; charset=UTF-8` unless it can use a fast plain `new Response(text)` path.
- `json()` serializes with `JSON.stringify(object)` and sets default `Content-Type` to `application/json`.
- `html()` sets default `Content-Type` to `text/html; charset=UTF-8` and can resolve promised/escaped HTML before responding.
- `redirect()` sets the `Location` header, URI-encodes non-ASCII locations, and returns an empty response with status `302` by default.
- `notFound()` calls the configured not-found handler, defaulting to an empty `Response` creator if none exists.
