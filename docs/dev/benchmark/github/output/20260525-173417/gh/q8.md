## Answer

- `createStore` is typed as `CreateStore` in `src/vanilla.ts`
- The `CreateStore` type has two overload signatures:
  1. `<T, Mos extends [StoreMutatorIdentifier, unknown][] = []>(initializer: StateCreator<T, [], Mos>): Mutate<StoreApi<T>, Mos>`
  2. `<T>(): <Mos extends [StoreMutatorIdentifier, unknown][] = []>(initializer: StateCreator<T, [], Mos>) => Mutate<StoreApi<T>, Mos>`
- The first overload takes a `StateCreator` directly and returns `Mutate<StoreApi<T>, Mos>`; the second is a curried form that returns a function
- `export const createStore = ((createState) => createState ? createStoreImpl(createState) : createStoreImpl) as CreateStore`
