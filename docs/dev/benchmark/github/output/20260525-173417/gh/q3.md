In `facebook/react`, find what happens when a component throws a promise (wakeable). What function handles it and what does it do?

## Answer

- When a component throws a promise (wakeable), the function `throwException` in `packages/react-reconciler/src/ReactFiberThrow.js` handles it
- It detects the thrown value is a wakeable by checking `typeof value.then === 'function'`
- It calls `resetSuspendedComponent()` to reset the suspended component's state
- It calls `getSuspenseHandler()` to find the nearest Suspense boundary
- It calls `markSuspenseBoundaryShouldCapture()` to mark the Suspense boundary to render the fallback
- It attaches a retry listener by stashing the wakeable on the boundary fiber's `retryQueue` so that when the promise resolves, React retries rendering the boundary
- If the suspended value is a "Suspensey resource" (noopSuspenseyCommitThenable), it sets the `ScheduleRetry` flag instead
