## Answer

- Top-level `biomejs/biome` directories include `.cargo`, `.changeset`, `.claude`, `.devcontainer`, `.github`, `crates`, `e2e-tests`, `fuzz`, `packages`, `plugins`, `scripts`, and `xtask`.
- `crates` is the main Rust workspace source tree: Biome's formatter/linter/parser/analyzer/runtime crates live here.
- `packages` contains npm/TypeScript-facing packages used to publish or integrate the Biome toolchain into the JavaScript ecosystem.
- `plugins` contains plugin-related packages/code.
- `e2e-tests` holds end-to-end tests, while `fuzz` contains fuzzing targets/corpora for robustness testing.
- `scripts` and `xtask` are automation/developer tooling areas; `xtask` is the Rust-style project task runner pattern.
- `.github` contains CI/release/workflow automation; `.cargo`, `Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `rustfmt.toml`, `clippy.toml`, and `deny.toml` show the Rust workspace/toolchain configuration.
- `.changeset`, `package.json`, `pnpm-workspace.yaml`, and `pnpm-lock.yaml` show that the Rust core is packaged and released through a JavaScript/npm workspace too.
- The primary language choice is Rust: GitHub language stats show Rust dominating the repository by size (about 23MB versus much smaller JavaScript/TypeScript). That reveals Biome is built as a high-performance native toolchain for parsing, linting, and formatting, with JS/TS packages mainly as distribution/integration layers.
