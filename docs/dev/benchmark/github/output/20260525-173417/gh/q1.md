Find where `useState` is defined in `facebook/react`. Which dispatcher method does it call?

## Answer

- `useState` is defined in `packages/react/src/ReactHooks.js` in `facebook/react`
- It calls `resolveDispatcher()` to get the current dispatcher, then calls `dispatcher.useState(initialState)`
- The dispatcher method it calls is `dispatcher.useState`
