## Answer

- `trpc/trpc` `packages/` includes core server/client packages such as `server`, `client`, `react-query`, `next`, plus adapters and tooling packages.
- The naming reveals layered architecture: server core/procedure/router layer, transport/client layer, React Query integration, Next.js integration, and platform adapters.
- The monorepo separates framework integrations from the unstable core so shared protocol/types can be reused across adapters.
