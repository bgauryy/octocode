## Answer

- `packages/vite/src/client/` contains browser client/HMR runtime code; `node/` contains the dev server, config, plugin container, resolver, optimizer, build, preview, SSR, watcher, and middleware implementation.
- `shared/` contains code shared between client and server; root entry files expose public APIs and CLI wiring.
- The main subsystems are config loading, plugin execution, module graph/HMR, dependency optimization, SSR transform/load, production build integration with Rollup, preview server, and asset/CSS handling.
