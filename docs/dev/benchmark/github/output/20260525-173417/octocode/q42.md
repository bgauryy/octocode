## Answer

- `honojs/hono` defines `Context` in `src/context.ts` with generic signature like `Context<E extends Env = any, P extends string = any, I extends Input = {}>`.
- It carries request/env/execution/render/notFound/error state and typed variables via the `Env`, path, and input generics.
- Response helpers include `body`, `text`, `json`, `html`, `redirect`, `notFound`, plus header/status/cookie-oriented helpers such as `header` and `status`.
