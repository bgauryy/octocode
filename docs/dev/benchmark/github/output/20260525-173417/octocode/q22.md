In `sveltejs/svelte`, find where `$state` values are represented as reactive signals at runtime. What is the core primitive and how is state mutation tracked?

## Answer

- In `sveltejs/svelte`, `$state` is a rune compiled to runtime reactive sources/signals in the client runtime, especially under `packages/svelte/src/internal/client/reactivity/`.
- The core primitive is a signal/source object, commonly created by `source`/`mutable_source`, holding value, reactions, equality/version metadata, and write tracking.
- State mutation is tracked by setter/write helpers that update the source value, mark dependent reactions dirty, and schedule effects/DOM updates.
