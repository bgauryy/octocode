## Answer

- `packages/` contains the main Next.js packages including `next`; `examples/` contains example apps; `test/` contains integration/e2e/unit tests.
- `docs/` contains documentation; `bench/` and `turbopack/` contain benchmarking and Turbopack-related code; `scripts/` contains repo automation.
- `.github/`, `.changeset/`, and root config files hold CI, release, workspace, lint, and build configuration.
