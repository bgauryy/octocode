## Answer

- `renderToReadableStream` is exported from React DOM server browser renderer files such as `packages/react-dom/src/server/ReactDOMFizzServerBrowser.js`.
- Its signature is `function renderToReadableStream(children: ReactNodeList, options?: Options): Promise<ReactDOMServerReadableStream>`.
- `options` include fields such as `identifierPrefix`, `namespaceURI`, `nonce`, `bootstrapScriptContent`, `bootstrapScripts`, `bootstrapModules`, `progressiveChunkSize`, `onError`, `onPostpone`, and form-state/resumability options.
