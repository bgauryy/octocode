Find `createSignal` in `solidjs/solid`. What mechanism makes updates fine-grained rather than component-level?

## Answer

- `solidjs/solid` implements `createSignal` in its reactive core, commonly `packages/solid/src/reactive/signal.ts`.
- `createSignal` creates a signal node with observers and returns a getter/setter pair; reading registers the current computation as an observer and writing notifies only dependent computations.
- This makes updates fine-grained because Solid re-executes affected computations/effects directly instead of re-rendering a whole component subtree like React `useState`.
