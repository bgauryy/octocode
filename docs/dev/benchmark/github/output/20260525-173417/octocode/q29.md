## Answer

- Next.js PPR uses a `Postpone` component in `packages/next/src/server/app-render/dynamic-rendering.ts` / App Render PPR helpers to intentionally postpone dynamic regions.
- `Postpone` interacts with React by throwing/using React's postpone mechanism so Fizz can emit a static shell while marking dynamic holes as postponed.
- The static shell is assembled in the App Router render pipeline using prerender/continue stream helpers such as `continueStaticPrerender`, postponed state, and Flight/render streams under `packages/next/src/server/app-render/`.
