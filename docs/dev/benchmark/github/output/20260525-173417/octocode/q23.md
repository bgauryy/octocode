In `vuejs/core`, find the function that processes `v-if` / `v-else-if` / `v-else` during template compilation. What AST node does it produce?

## Answer

- Vue processes `v-if` / `v-else-if` / `v-else` in `packages/compiler-core/src/transforms/vIf.ts`.
- The main function is `processIf`, used by the `transformIf` structural directive transform.
- It produces an `IF` AST node (`IfNode`) containing `branches` (`IfBranchNode`) for each conditional branch.
