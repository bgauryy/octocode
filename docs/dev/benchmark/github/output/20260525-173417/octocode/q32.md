Find where `parse` is defined in `colinhacks/zod` (v4 core). What internal method does it call to validate, and what happens when the validation result is a Promise?

## Answer

- In `colinhacks/zod` v4 core, `parse` is defined in `packages/zod/src/v4/core/parse.ts`.
- It calls the schema internals via `schema._zod.run(...)` / core parsing machinery to validate the input and collect issues.
- If the validation result is a `Promise`, synchronous `parse` throws an error telling the caller to use the async API; `parseAsync` awaits the promise.
