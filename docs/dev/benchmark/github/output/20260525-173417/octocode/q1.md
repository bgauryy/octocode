Find where `useState` is defined in `facebook/react`. Which dispatcher method does it call?

## Answer

- `useState` is exported from `packages/react/src/ReactHooks.js` in `facebook/react`.
- Its implementation calls `resolveDispatcher()` and returns `dispatcher.useState(initialState)`.
