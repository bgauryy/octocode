### Q35 — How does Vitest execute a single test? (`runTest`)

In `vitest-dev/vitest`, read `packages/runner/src/run.ts`. What are the key steps in `runTest(test, runner)`, and how does Vitest handle `retry` and `repeat`?

## Answer

- `runTest(test, runner)` in `packages/runner/src/run.ts` marks the test running, calls hooks, executes the test function through the runner/context, records result/errors/duration, and updates task state.
- It handles `retry` by rerunning failed attempts until the retry budget is exhausted, preserving errors/tasks metadata for each attempt.
- It handles `repeat` by executing the same test multiple times as configured, applying the same lifecycle/error handling around each run.
