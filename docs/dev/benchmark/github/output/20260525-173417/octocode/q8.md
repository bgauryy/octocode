## Answer

- In `pmndrs/zustand` `src/vanilla.ts`, `createStore` has type `CreateStore`.
- `CreateStore` is overloaded as `<T, Mos extends [StoreMutatorIdentifier, unknown][] = []>(initializer: StateCreator<T, [], Mos>): Mutate<StoreApi<T>, Mos>` and `<T>(): <Mos extends [StoreMutatorIdentifier, unknown][] = []>(initializer: StateCreator<T, [], Mos>) => Mutate<StoreApi<T>, Mos>`.
