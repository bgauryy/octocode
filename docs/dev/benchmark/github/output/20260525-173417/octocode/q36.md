In `withastro/astro`, find `packages/astro/src/runtime/server/hydration.ts`. What does `extractDirectives()` do and what is `HydrationMetadata`?

## Answer

- `extractDirectives()` in `packages/astro/src/runtime/server/hydration.ts` scans component props for `client:*` hydration directives.
- It removes/normalizes directive props, validates the directive, captures directive value and component URL/export metadata, and returns cleaned props plus hydration metadata.
- `HydrationMetadata` describes how an island should hydrate: directive/client strategy, component URL/export, serialized props, and related hydration options needed by Astro's island renderer.
