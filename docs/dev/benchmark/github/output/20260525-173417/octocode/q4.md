Search `vercel/next.js` for `startTransition` usage in client code. What does it wrap?

## Answer

- Yes: Next.js App Router imports and uses React's `startTransition` in client components under `packages/next/src/client/components/`.
- In `app-router.tsx`, `router.push`, `router.replace`, and `router.refresh` wrap navigation/refresh dispatches in `startTransition`.
- In redirect/error-boundary client paths, `startTransition` wraps router state updates triggered by redirects or recovery.
