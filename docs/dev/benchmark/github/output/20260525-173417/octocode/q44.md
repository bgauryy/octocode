Using `withastro/astro` and `vercel/next.js`:
1. Find the SSR render entry function in each repo.
2. How does each stream HTML to the client?
3. How does Astro's islands model differ architecturally from Next.js's React Server Components?

## Answer

- Astro's SSR entry is `packages/astro/src/runtime/server/render/page.ts` with `renderPage()` and related server render pipeline functions.
- Next.js App Router SSR entry is `packages/next/src/server/app-render/app-render.tsx`, with streaming helpers in `stream-ops.web.ts` calling React's `renderToReadableStream`.
- Astro streams mostly HTML with island hydration metadata for selected `client:*` components; Next streams React Server Components/Fizz output and Flight data for a React component tree.
- Architecturally, Astro islands keep most components server/static and hydrate opt-in islands, while Next RSC splits Server/Client Components inside a React-driven app tree.
