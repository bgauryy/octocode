## Answer

- Next.js calls/imports `renderToReadableStream` in `packages/next/src/server/app-render/stream-ops.web.ts` and uses it from the App Router rendering pipeline.
- React defines the server API in `packages/react-dom/src/server/ReactDOMFizzServerBrowser.js` / related React DOM server entry files.
- The path is Next App Router render code → `stream-ops.web.ts` → `react-dom/server` `renderToReadableStream` → React Fizz server implementation.
