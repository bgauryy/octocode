## Answer

- `vercel/next.js`: the App Router server renderer is in `packages/next/src/server/app-render/app-render.tsx`; it calls React's `renderToReadableStream` for streaming RSC/HTML work.
- `remix-run/react-router`: the Node server entry template uses React DOM Server's `renderToPipeableStream` from `react-dom/server`.
- `nuxt/nuxt`: Nuxt's SSR renderer uses Vue server-renderer APIs such as `renderToString` to produce server HTML.
