In `facebook/react`, find what happens when a component throws a promise (wakeable). What function handles it and what does it do?

## Answer

- React captures a thrown promise/wakeable in `packages/react-reconciler/src/ReactFiberThrow.js` inside `throwException`.
- `throwException` marks the source fiber incomplete, detects the thrown value as a `Wakeable`, resets the suspended component, finds the nearest `Suspense` boundary, marks it to capture, and attaches ping/retry listeners so resolving the wakeable can schedule another render.
