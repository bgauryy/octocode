Find the core navigation primitive in `vercel/next.js`, `remix-run/react-router`, and `TanStack/router`.

## Answer

- In `vercel/next.js`, the App Router navigation primitive is `AppRouterInstance.push(href, options?)`, implemented by wrapping `navigate(href, 'push', scroll)` in `startTransition` in `packages/next/src/client/components/app-router.tsx`.
- In `remix-run/react-router`, the primary primitive is `navigate(to, opts?)` / `navigator.push` exposed through `useNavigate` and the router's `navigate` implementation.
- In `TanStack/router`, the core primitive is `router.navigate` / `NavigateFn`, which builds a location and commits it through the router history.
