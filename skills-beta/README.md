# skills-beta

Tested skills. They are used and judged in this repo, and they are not published.

| Tree | Role |
|---|---|
| [`skills/`](../skills/) | Public skills. Shipped with the CLI. |
| `skills-beta/` | Tested skills. Not installed by `octocode skill install`. Promote a folder into `skills/` only after the trial holds. |
| [`skills-dev/`](../skills-dev/) | Skills for working on this repository. Not published. |

## In trial

| Skill | Use when |
|---|---|
| [`octocode-context-audit`](octocode-context-audit/) | Measure always-loaded agent context (instructions, skills, MCP schemas) against real tool/skill usage; flag bloat, broken links, unused or bypassed tools |
