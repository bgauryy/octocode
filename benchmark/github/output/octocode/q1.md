## Answer

- Next.js call site: `packages/next/src/server/app-render/app-render.tsx` gets `renderToReadableStream` from `componentMod`/React Server DOM Webpack and passes it through the app-render/Flight rendering path; supporting wrappers/types are in `packages/next/src/server/app-render/stream-ops.web.ts` and `stream-ops.node.ts`.
- For Pages rendering, `packages/next/src/server/render.tsx` has `renderToString(element)` that calls `ReactDOMServerPages.renderToReadableStream(element)` and waits for `allReady`.
- React definition for the RSC Flight stream: `packages/react-server-dom-webpack/src/server/ReactFlightDOMServerEdge.js` defines `function renderToReadableStream(...)`, re-exported through `packages/react-server-dom-webpack/src/server/react-flight-dom-server.edge.js` and package entrypoints.
- React DOM Web-stream SSR exports also forward `renderToReadableStream` from `packages/react-dom/server.edge.js` / `server.node.js` to `packages/react-dom/src/server/ReactDOMFizzServerEdge.js`/related Fizz server files.
