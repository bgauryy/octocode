## Answer

- **Main dev server entry file**: `packages/vite/src/node/server/index.ts` (1,431 lines)
- **Dev server entry point function**: `createServer(inlineConfig)` — exported from `packages/vite/src/node/server/index.ts`. It delegates immediately to `_createServer(inlineConfig, { listen: true })`.
- **First function called on startup** (inside `_createServer`):
  1. `disableCache()` — disables the Vite task client cache (since dev server outputs cannot be replayed from cache)
  2. `resolveConfig(inlineConfig, 'serve')` — resolves the full Vite config for the `serve` command (this is the first substantial async call)
  3. `initPublicFiles(config)` — starts initializing public files (runs concurrently as a promise)
  4. `resolveHttpsConfig(config.server.https)` — resolves HTTPS options
  5. `connect()` — creates the connect middleware server
  6. `resolveHttpServer(middlewares, httpsOptions)` — creates the HTTP server
  7. `createWebSocketServer(httpServer, config, httpsOptions)` — creates the WebSocket server for HMR
