## Answer

- **Main entry point for the dev server**: `packages/vite/src/node/server/index.ts`
  - The exported `createServer` function (line ~473) delegates immediately to `_createServer(inlineConfig, { listen: true })`.
  - The actual implementation is in `_createServer` (async).
- **First function called on startup** (in `_createServer`):
  1. `disableCache()` — disables caching (from `@voidzero-dev/vite-task-client`) since the dev server is a long-running interactive process whose outputs cannot be replayed from cache.
  2. Then `resolveConfig(inlineConfig, 'serve')` — resolves the Vite configuration for the `serve` command.
  3. Then `initPublicFiles(config)` (as a promise, non-blocking).
  - So the **first call on startup** is `disableCache()`.
