## Answer

- **Main entry point for the dev server**: `packages/vite/src/node/server/index.ts`
  - The exported `createServer(inlineConfig)` function at line 473 is the public entry point
  - It delegates to `_createServer(inlineConfig, { listen: true })` at line 479 which contains the actual implementation
- **First function called on startup**: `disableCache()` — this is the very first call inside `_createServer`'s body (before config resolution), invoked to disable the cache system since the dev server is a long-running, interactive process whose outputs cannot be replayed from a cache
  - Immediately after: `resolveConfig(inlineConfig, 'serve')` resolves the Vite config
  - Then: `initPublicFiles(config)` initializes public file tracking
  - Then: `resolveHttpsConfig(...)`, `connect()`, `resolveHttpServer(...)`, `createWebSocketServer(...)` build up the HTTP + WebSocket layer
