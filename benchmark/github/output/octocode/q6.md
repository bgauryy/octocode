## Answer

- **First 4.x release**: `4.0.0` (2022-12-09)
  - **Main changes** (from the `v4.0.4` tag's CHANGELOG):
    - Upgraded to **Rollup 3** — main focus; simplified internal asset handling
    - `@vitejs/plugin-vue` and `@vitejs/plugin-react` moved out of the Vite core monorepo into independent repos
    - New `@vitejs/plugin-react-swc` plugin using **SWC** instead of Babel for faster cold start and HMR in development
    - Modern browser build now targets `safari14` by default (ES2020 compatibility; enables `BigInt`, no nullish-coalescing transpilation)
    - **CSS default export deprecated** — use `?inline` query suffix instead to avoid double loading
    - `hot.decline()` removed from HMR client (was never implemented)
    - CLI keyboard shortcuts added
    - Support for `patch-package` in pre-bundling, multiline env values, `kB` build output, dotenv-expand for `process.env`
- **Latest release** listed in the main branch `packages/vite/CHANGELOG.md`: `8.0.16` (2026-06-01)
  - Note: The main branch CHANGELOG contains full entries from 5.x onwards; 4.x and earlier are collapsed to one-line references pointing to their tagged CHANGELOG branches.
