## Answer

- **Latest release version**: `8.0.16` (2026-06-01) — fixed security issues rejecting UNC paths and Windows alternate paths in `launch-editor-middleware`.
- **First 4.x release**: `4.0.0` (2022-12-09).
- What `4.0.0` changed (main changes):
  - **Rollup 3** upgrade — simplified internal asset handling.
  - **Framework plugins moved out of the core monorepo**: `@vitejs/plugin-vue` and `@vitejs/plugin-react` moved to independent repositories (`vitejs/vite-plugin-vue` and `vitejs/vite-plugin-react`).
  - **New `@vitejs/plugin-react-swc`** plugin: uses SWC instead of Babel during development for significantly faster cold start and HMR on large React projects.
  - **Browser target** changed to `safari14` by default (wider ES2020 compatibility; `BigInt` and nullish coalescing no longer transpiled).
  - **CSS default export deprecated**: importing `.css` as default string now requires `?inline` query suffix to avoid double-loading.
  - **CLI keyboard shortcuts** added (e.g., press `u` to show server URL).
  - **Multiline values** in `.env` files now supported.
  - **SSR CJS dedupe/mode support removed**.
  - esbuild default charset set to `utf8`.
  - Cleaner build logs, switched to `kB` units to match browser DevTools.
  - Support for `patch-package` when pre-bundling dependencies.
  - `HMR invalidate` message support.
