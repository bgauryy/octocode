## Answer

- **First 4.x release**: `4.0.0` released **2022-12-09**. Key changes:
  - Main objective was upgrading to **Rollup 3**, simplifying Vite's internal asset handling
  - Framework plugins (`@vitejs/plugin-vue`, `@vitejs/plugin-react`) were moved out of the Vite core monorepo to independent repositories
  - New `@vitejs/plugin-react-swc` plugin introduced — uses SWC instead of Babel for significantly faster cold start and HMR
  - Modern browser build target changed to `safari14` by default for wider ES2020 compatibility (enables `BigInt`, stops transpiling nullish coalescing)
  - CSS default export from `.css` files deprecated; `?inline` suffix required to avoid double loading
  - Added CLI keyboard shortcuts, patch-package support for pre-bundling, cleaner build logs, `kB` unit in reporter, improved SSR error messages
- **Latest release**: `8.0.16` (released 2026-06-01) in the current `main` branch
