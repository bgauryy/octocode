In `facebook/react`, find what happens when a component throws a promise (wakeable). What function handles it and what does it do?

## Answer

- In `facebook/react`, thrown promises/wakeables are handled by `throwException(...)` in `packages/react-reconciler/src/ReactFiberThrow.js`.
- `throwException` first marks the source fiber `Incomplete`; when `value` is an object with a `.then` function, React treats it as a wakeable and calls `resetSuspendedComponent(sourceFiber, rootRenderLanes)`.
- It finds the current Suspense handler with `getSuspenseHandler()`. For `SuspenseComponent`/`SuspenseListComponent`/`ActivityComponent`, it records that the render suspended (`renderDidSuspend...` heuristics), clears `ForceClientRender`, and calls `markSuspenseBoundaryShouldCapture(...)` so the boundary captures and renders its fallback.
- For normal wakeables, React stores the wakeable in the boundary retry queue (`suspenseBoundary.updateQueue`, a `Set`) and, in concurrent mode, calls `attachPingListener(root, wakeable, rootRenderLanes)` so resolution pings the root and retries rendering the boundary.
- If no Suspense boundary is found, concurrent roots attach a ping listener and suspend indefinitely/delay if possible; legacy roots convert the suspension into an error telling the user to wrap suspending updates in `startTransition`.
