- **`performWorkOnRoot`** (the replacement for `performConcurrentWorkOnRoot`): Signature `performWorkOnRoot(root: FiberRoot, lanes: Lanes, forceSync: boolean): void`. It is the main entry point for the React work loop. It decides whether to use time-slicing (concurrent rendering) or synchronous rendering based on `forceSync`, whether the lanes are blocking or expired, and whether the root is prerendering. It then calls either `renderRootConcurrent(root, lanes)` or `renderRootSync(root, lanes, true)`, handles errors/retries, and calls `finishConcurrentRender` to commit the completed work.
