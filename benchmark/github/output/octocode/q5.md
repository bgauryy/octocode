  - (42+ additional exported functions beyond line 1100)
- **Note**: `performConcurrentWorkOnRoot` does not exist in the current `main` branch of `facebook/react` — the work loop has been significantly refactored. The concurrent rendering entry point is now handled through `scheduleUpdateOnFiber` → `ensureRootIsScheduled` which ultimately dispatches work via the React Scheduler. The old `performConcurrentWorkOnRoot` function was the scheduler callback that ran the work loop for a concurrent root; it would call `renderRootConcurrent`, handle suspended/interrupted states, and commit finished work — its responsibility has been broken into several smaller functions in the current implementation.
