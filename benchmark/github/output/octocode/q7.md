## Answer

- Next.js App Router path: `packages/next/src/server/app-render/stream-ops.web.ts` imports `renderToReadableStream` from `react-dom/server`; `renderToWebFizzStream(...)` calls `renderToInitialFizzStream({ ReactDOMServer: { renderToReadableStream }, element, streamOptions })`.
- The immediate helper is `packages/next/src/server/stream-utils/node-web-streams-helper.ts`: `renderToInitialFizzStream(...)` traces `AppRenderSpan.renderToReadableStream` and calls `ReactDOMServer.renderToReadableStream(element, streamOptions)`.
- Next.js Pages Router also has `packages/next/src/server/render.tsx`, where local `renderToString(element)` calls `ReactDOMServerPages.renderToReadableStream(element)`, awaits `allReady`, and converts it to a string.
- React definition: for the browser/web stream server build, `packages/react-dom/src/server/ReactDOMFizzServerBrowser.js` defines `function renderToReadableStream(children, options)`.
- React export path: `packages/react-dom/src/server/react-dom-server.browser.stable.js` re-exports `renderToReadableStream` from `./ReactDOMFizzServerBrowser.js`.
- Internally React's `renderToReadableStream` creates a `ReadableStream`, attaches `stream.allReady`, builds a Fizz request with `createRequest(...)`, wires shell/error/all-ready callbacks, handles abort signals, and starts rendering with `startWork(request)`.
