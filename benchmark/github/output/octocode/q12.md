### Q12 — Vue 3 template compiler: `v-if`

In `vuejs/core`, find the function that processes `v-if` / `v-else-if` / `v-else` during template compilation. What AST node does it produce?

## Answer

- Vue 3 processes template `v-if`/`v-else-if`/`v-else` in `packages/compiler-core/src/transforms/vIf.ts`.
- The transform entry is `transformIf`, created with `createStructuralDirectiveTransform(/^(?:if|else|else-if)$/ , ...)`, which delegates to `processIf(...)`.
- `processIf(node, dir, context, processCodegen)` validates missing expressions, processes/prefixes the expression when needed, and for `v-if` creates a branch with `createIfBranch(...)`.
- For `v-if`, it creates an AST node `IfNode` with `type: NodeTypes.IF`, `loc: cloneLoc(node.loc)`, and `branches: [branch]`, then replaces the original element with `context.replaceNode(ifNode)`.
- For `v-else-if`/`v-else`, `processIf` walks siblings to find the adjacent prior `NodeTypes.IF`, removes comments/whitespace, creates another `IfBranchNode`, checks duplicate keys, pushes it into `sibling.branches`, traverses that branch, and errors if no adjacent `v-if` exists.
- The branch node is `IfBranchNode` with `type: NodeTypes.IF_BRANCH`, `condition` equal to `dir.exp` except `v-else` where it is `undefined`, `children` from the `<template>` or original node, `userKey`, and `isTemplateIf`.
- Codegen later builds nested conditional expressions: `createCodegenNodeForBranch` returns a `createConditionalExpression(...)` for conditional branches and a comment fallback (`CREATE_COMMENT`) for failed `v-if` branches; `v-else` returns its children codegen directly.
