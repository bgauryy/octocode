## Answer

- **PR #306** — "feat: jsx middleware" is the first merged PR that introduced JSX/JSX renderer support in `honojs/hono`.
  - URL: https://github.com/honojs/hono/pull/306
  - Author: `yusukebe`
  - Target branch: `master`
- **Motivation (from PR body)**: "Close #300" — minimal description. The motivation is inferred from the code: Hono needed a server-side rendering capability using JSX syntax (without a virtual DOM), similar to React but for Cloudflare Workers and Deno SSR.
- **Files added or changed to implement it** (11 files total):

  - `src/middleware/mustache/mustache.ts` — Minor type cleanup
