## Answer

**Main entry point for the Vite dev server:** `packages/vite/src/node/server/index.ts`

This file exports `createServer(inlineConfig)` (line 473), which is a thin wrapper that calls `_createServer(inlineConfig, { listen: true })` (line 476). The actual implementation is `_createServer` (async function starting at line 479).

**First function called on startup inside `_createServer`:**
`disableCache()` — line 491 — the very first call after the function opens. This disables caching for the dev server, since it is a long-running interactive process whose outputs cannot be replayed from cache.
