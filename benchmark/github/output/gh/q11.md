## Answer

- **Main dev server entry point**: `packages/vite/src/node/server/index.ts`
- Discovery path: `packages/vite/src/` → `node/` → `server/` → `index.ts`

**First function called on startup:**
The primary public API is `createServer()` (line 473), which delegates to `_createServer()` (line 479). The first meaningful call inside `_createServer` is:

```typescript
disableCache()  // line 491 — disables Vite's task cache for the long-running dev process
```

Then immediately:
```typescript
const config = isResolvedConfig(inlineConfig)
    ? inlineConfig
    : await resolveConfig(inlineConfig, 'serve')  // line 495
```

So the first startup call is `disableCache()` followed by `resolveConfig()` (config resolution and plugin pipeline setup), then `resolveHttpsConfig()`, HTTP server creation, filesystem watcher initialization, and middleware setup.
