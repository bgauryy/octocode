In `sveltejs/svelte`, find where `$state` values are represented as reactive signals at runtime. What is the core primitive and how is state mutation tracked?

## Answer

- Svelte 5 `$state` runtime representation is in `packages/svelte/src/internal/client/reactivity/sources.js` and `packages/svelte/src/internal/client/proxy.js`.
- The core primitive is a signal/source: `source(v, stack)` (also exported as `state`) creates a `Value`/`Source` object with flags, value `v`, reactions, equality, etc.; reads go through `get(source)` and writes through `set(source, value)`/`internal_set`.
- Objects/arrays created by `$state` are wrapped by `proxy(value, parent, prev)` in `proxy.js`; it maintains a `Map` from property names to per-property sources and a version source.
- Mutation tracking: proxy `get` lazily creates/reads the property source with `get(s)` so the current reaction subscribes; proxy `set` creates or updates the property source via `set(s, ...)`, updates array length sources when needed, and bumps the version source so dependent effects are invalidated.
