## Answer

- Problem: PR `trpc/trpc#7336` fixes React 19 coercing tRPC recursive proxy objects to primitives by calling `valueOf()`, `toString()`, or `toJSON()`. Before the fix, the proxy `get` trap returned another proxy for those keys, which could break primitive consumers or recurse indefinitely.
- Changed files: `packages/server/src/unstable-core-do-not-import/createProxy.ts` adds coercion-key handling in the recursive proxy; `packages/server/src/unstable-core-do-not-import/createProxy.test.ts` adds regression tests for `valueOf`, `toString`, and `toJSON` while ensuring normal proxy chaining still works.
- Core technical fix: special-case `valueOf`/`toString`/`toJSON` in `createInnerProxy` and return a plain function that yields a debug string like `tRPC.proxy(foo.bar)` instead of returning another recursive proxy.
- React 19 specificity: React 19 may coerce values during rendering/string interpolation/logging and therefore touches those primitive-conversion methods on arbitrary values; that exposed tRPC's recursive proxy behavior for these keys.
