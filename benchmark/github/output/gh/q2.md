In `facebook/react`, find what happens when a component throws a promise (wakeable). What function handles it and what does it do?

## Answer

- In `facebook/react`, a thrown promise/thenable is handled by `throwException(...)` in `packages/react-reconciler/src/ReactFiberThrow.js`.
- `throwException` treats a thrown thenable as a wakeable: it resets the suspended component, finds the nearest Suspense boundary, marks that boundary to capture/render its fallback, and records the wakeable on the boundary's retry queue.
- For concurrent rendering it attaches a ping listener (`attachPingListener`) so that when the wakeable resolves React can mark the root as pinged and retry rendering the suspended work.
- If no Suspense boundary can catch it, React either suspends the root indefinitely in concurrent mode or reports an error in legacy sync mode.
