## Answer

**facebook/react — `useState`**
- File: `packages/react/src/ReactHooks.js`, line 66
- Definition: `export function useState<S>(initialState: (() => S) | S): [S, Dispatch<BasicStateAction<S>>]`
- This is a thin dispatcher wrapper — it calls `dispatcher.useState(initialState)` where dispatcher is the currently active React reconciler dispatcher.

**vuejs/core — `ref()`**
- File: `packages/reactivity/src/ref.ts`, line 64
- Definition: `export function ref(value?: unknown) {`
- Overloaded function (lines 59, 62, 64); the implementation at line 64 calls `createRef(value, false)`.

**solidjs/solid — `createSignal`**
- File: `packages/solid/src/server/reactive.ts` (server-side implementation), line 76; the main runtime implementation lives in `packages/solid/src/reactive/signal.ts` (file exceeds GitHub inline size limit — exact line not confirmed via `gh api` contents endpoint).
- Definition: `export function createSignal<T>(value: T, options?): [() => T, (v: T) => T]` — returns a `[getter, setter]` accessor tuple backed by a `SignalState` node in the reactive graph.
