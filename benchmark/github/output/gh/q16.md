### Q16 — Where is `parse()` implemented in Zod v4?

Find where `parse` is defined in `colinhacks/zod` (v4 core). What internal method does it call to validate, and what happens when the validation result is a Promise?

## Answer

- Zod v4 core defines `parse` in `packages/zod/src/v4/core/parse.ts` as `export const parse: $Parse = _parse(errors.$ZodRealError)`.
- The internal parser calls `schema._zod.run({ value, issues: [] }, ctx)` to validate/coerce the input.
- If that result is a `Promise` in the synchronous `parse` path, Zod throws `$ZodAsyncError` telling the caller to use `.parseAsync()` instead.
- After a synchronous result, if `result.issues.length` is nonzero it throws the configured Zod error; otherwise it returns `result.value`.
