## Answer

- `vercel/next.js`: the Pages Router primitive is `Router.push()` in `packages/next/src/shared/lib/router/router.ts`; it delegates to `this.change('pushState', url, as, options)`, while the App Router also patches/integrates `window.history.pushState` in `packages/next/src/client/components/app-router.tsx`.
- `remix-run/react-router`: the core primitive is the data router `navigate(to, opts)` in `packages/react-router/lib/router/router.ts`; public APIs such as `useNavigate()`/`<Navigate>` call into that router navigation function.
- `TanStack/router`: the core primitive is `router.navigate(...)` on the router instance in `packages/router-core/src/router.ts`; framework hooks/components such as `packages/react-router/src/useNavigate.tsx` wrap and call it.
