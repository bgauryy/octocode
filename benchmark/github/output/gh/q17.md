### Q17 — How does Hono chain middleware? (`compose()`)

In `honojs/hono`, find `src/compose.ts`. How does `compose()` build and execute the middleware chain? What prevents `next()` from being called twice?

## Answer

- `honojs/hono` implements `compose()` in `src/compose.ts`; it returns a dispatcher function that starts at middleware index `0` and recursively dispatches the next index.
- For each middleware, `dispatch(i)` picks `middleware[i]`, builds a `next` function that calls `dispatch(i + 1)`, and invokes the middleware with `(context, next)`; if the end of the chain is reached it calls the optional final handler.
- Execution is promise-based/async: middleware can `await next()` to continue the chain and then run post-processing after downstream middleware returns.
- Double `next()` protection is by index tracking: `dispatch` keeps the previous/current index, and if a middleware tries to dispatch an index that is not greater than the last dispatched index, it rejects/throws an error that `next()` was called multiple times.
