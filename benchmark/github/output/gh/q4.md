### Q4 — Multi-keyword narrowing search `[SEARCH]`

In `vercel/next.js`, find files that contain **both** `ppr` and `Postpone` in the same file.
1. How many files match?
2. List all file paths.

## Answer

- `gh search code` cannot natively express file-level AND intersection; the approach requires two separate queries and a client-side intersection.
- Each query returns at most 100 results; the true match count could be higher if either keyword appears in more than 100 files.
- From the intersection of the top-100 results for each keyword: **32 files** contain both `ppr` and `Postpone`.
