## Answer

- `vercel/next.js`: App Router SSR is in `packages/next/src/server/app-render/app-render.tsx`; it obtains/calls React Server Components' `renderToReadableStream` from the route/component module / `react-server-dom-webpack/server.*` to produce the Flight stream, and then streams HTML around that result.
- `remix-run/react-router`: the framework SSR entry is the user/default `entry.server.tsx` generated from `packages/react-router-dev/config/defaults/entry.server.node.tsx`; `handleRequest` renders `<ServerRouter context={routerContext} url={request.url} />` with React DOM's `renderToPipeableStream`.
- `nuxt/nuxt`: Nitro's request handler `packages/nitro-server/src/runtime/handlers/renderer.ts` calls `renderer.renderToString(ssrContext)`; the renderer contract/wrapper is in `packages/nitro-server/src/runtime/utils/renderer/build-files.ts` and delegates to Vue/Nuxt server `renderToString` to produce HTML.
