## Answer

**First `4.x` release: `4.0.0` (2022-12-09)**

Changes in `4.0.0` (as listed in the CHANGELOG at the `v4.0.0` tag):
- Added `\0` prefix to virtual file IDs (`#11261`)
- Updated esbuild to `0.16.3` (`#11271`)

(The `4.0.0` release was a major version bump on top of many beta commits; the stable release itself had only these two commits above the beta trail.)

**Latest release listed in the current CHANGELOG:** `8.0.16` (2026-06-01)

**Method note:** The current `packages/vite/CHANGELOG.md` on `main` (~237 KB, 2,103 lines) only summarises pre-5.x history as "See [X.Y.Z changelog]" links. Getting the `4.0.0` content required fetching the CHANGELOG from the `v4.0.0` git tag via the blob API.
