## Answer

- The current `packages/vite/CHANGELOG.md` only contains entries from 6.0 onwards (the current latest is `8.0.16`). Older changelogs are referenced under "Previous Changelogs" at the bottom of the file.
- The 4.x changelog was retrieved from the `v4.0.0` tag: `gh api repos/vitejs/vite/contents/packages/vite/CHANGELOG.md?ref=v4.0.0`.

**1. First 4.x release: `4.0.0` (2022-12-09)**
Changes:
- `chore: add \0 to virtual files id (#11261)` 
- `chore(deps): esbuild 0.16.3 (#11271)`

The key changes in the 4.0.0 release were the switch to esbuild 0.16.x and Rollup 3.x, plus virtual file improvements.

- `deps: reject UNC paths for launch-editor-middleware`
- `reject windows alternate paths`
