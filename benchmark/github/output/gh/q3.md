## Answer

- Yes. `vercel/next.js` uses React `startTransition` in client-side App Router code.
- In `packages/next/src/client/components/app-router.tsx`, it wraps `dispatchAppRouterAction(...)` when handling router/history-related actions.
- In `packages/next/src/client/components/app-router-instance.ts`, it wraps the action-queue dispatch for app-router instance methods.
- Related usages wrap client navigation/error recovery/server-action updates: `packages/next/src/client/app-call-server.ts` wraps `dispatchAppRouterAction({ type: ACTION_SERVER_ACTION, ... })`; `redirect-boundary.tsx` wraps `router.push`/`router.replace`; `error-boundary.tsx`/`catch-error.tsx` wrap `refresh()` retries.
