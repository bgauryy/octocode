### Q12 — Vue 3 template compiler: `v-if`

In `vuejs/core`, find the function that processes `v-if` / `v-else-if` / `v-else` during template compilation. What AST node does it produce?

## Answer

- Vue 3 handles `v-if` / `v-else-if` / `v-else` in `packages/compiler-core/src/transforms/vIf.ts`.
- The main function is `processIf(node, dir, context, processCodegen?)`, used by the `transformIf` structural directive transform.
- For an initial `v-if`, it replaces the element with an `IfNode` AST node (`type: NodeTypes.IF`) containing a `branches` array.
- Each condition arm is represented as an `IfBranchNode` created by `createIfBranch(...)`; `v-else-if`/`v-else` branches are attached to the previous sibling `IfNode`'s `branches`.
