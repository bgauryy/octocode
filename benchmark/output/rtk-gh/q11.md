## Answer

- `packages/next/src/server/send-response.ts` — `export async function sendResponse` (line 14) pipes the RSC/`Response` body to the Node HTTP response.
- Stream connection: `await pipeToNodeResponse(response.body, originalResponse, waitUntil)` at line 80.
