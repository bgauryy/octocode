## Answer

- Server-side `revalidateTag` is defined in `packages/next/src/server/web/spec-extension/revalidate.ts` at line 34 (`export function revalidateTag(tag: string, profile: string | CacheLifeConfig)`).
- On call it appends to the work-store queue: `store.pendingRevalidatedTags.push({ tag, profile, })` (lines 224–227 in the same file, inside `function revalidate(...)`).
- Consumer: `executeRevalidates` in `packages/next/src/server/revalidation-utils.ts` reads `workStore.pendingRevalidatedTags` and calls `revalidateTags(pendingRevalidatedTags, workStore.incrementalCache, workStore)` (lines 186–201).
