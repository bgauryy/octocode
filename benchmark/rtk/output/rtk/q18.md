## Answer

The npm package named exactly `rtk` is **not** `rtk-ai/rtk`.

1. What it does: it is an “Agnostic software release tool for managing versions on changelog (keep-a-changelog), multi-format files (JSON, Makefile, text, TOML, YAML), and also for tagging source code of a Git repo.”
2. Current version: **4.2.0**. Weekly downloads from the npm downloads API for `last-week`: **1912** for 2026-05-27 through 2026-06-02.
3. Repository URL: `git+https://github.com/cliffano/rtk.git`.

Naming conflict risk: **yes**. The exact npm name `rtk` is already occupied by Cliffano’s release/versioning tool, so `rtk-ai/rtk` would need a scoped/different package name or ownership transfer to publish on npm.
