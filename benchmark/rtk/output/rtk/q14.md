## Overall Module Responsibility

`discover/` has two jobs (per README):
1. **Live command rewriting** — Every LLM agent hook calls `rtk rewrite "raw command"`. The module tokenizes (lexer), classifies (registry+rules), and rewrites to `rtk <cmd>` equivalent.
2. **History analysis** — `rtk discover` scans past LLM sessions (provider), classifies every command with the same logic, and reports adoption metrics (report).
