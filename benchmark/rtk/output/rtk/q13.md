## Answer

In `src/cmds/git/diff_cmd.rs`, `condense_unified_diff()` handles unified diffs as follows:

1. **Kept:**
   - The current file path from the `+++ b/...` line.
   - Per-file summary lines like `[file] path (+N -N)`.
   - All actual changed lines: lines starting with `+` (but not `+++`) and lines starting with `-` (but not `---`).

2. **Stripped/compressed:**
   - Diff metadata/header lines: `diff --git`, `--- ...`, `+++ ...` are not printed directly.
   - Hunk headers (`@@ ... @@`) are not kept.
   - Unchanged context lines are ignored.
   - For files with more than 10 total changed lines, it appends a summary line `... +{total - 10} more`.

3. **Maximum context lines per hunk:** **0**. The file comment says “Ultra-condensed diff - only changed lines, no context,” and the loop only records `+`/`-` changed lines while ignoring non-changed context and `@@` hunk headers.

Relevant comment from the code: “Never truncate diff content — users make decisions based on this data. Only strip diff metadata (headers, @@ hunks); all +/- lines shown in full.”
