## Answer

## Largest `.rs` file under `src/`

**`src/discover/registry.rs`** — **4,105 lines** (123,020 bytes)

This is the rewrite rule engine (the hot path for every LLM hook invocation). It:
- Implements the `classify()` function that every hook calls when an LLM runs a command
- Contains 60+ regex patterns for matching known shell commands to their `rtk` equivalents
- Handles compound command splitting (via lexer tokens), guard conditions (skip patterns), and the complete rewrite decision tree
- Module-level doc: *"Matches shell commands against known RTK rewrite rules to decide how to handle them."*
