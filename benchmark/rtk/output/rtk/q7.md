## Answer

Files under `src/discover/`:

- `README.md` — documentation for the discover subsystem.
- `lexer.rs` — tokenizes shell command strings into parsed tokens (`Arg`, `Operator`, `Pipe`, `Redirect`, `Shellism`) and supports splitting command chains/operators.
- `mod.rs` — module entry point. It wires together the Claude session provider, command registry/classifier, report generation, aggregation buckets, and the `run(...)` function for discovery.
- `provider.rs` — reads Claude Code session logs from disk and extracts command history. It defines `ExtractedCommand`, `SessionProvider`, and `ClaudeProvider`.
- `registry.rs` — matches shell commands against known RTK rewrite rules and classifies them as supported/unsupported/ignored. It also estimates average token counts/savings by category.
- `report.rs` — data types and rendering/reporting support for supported/unsupported commands and agent integration status.
- `rules.rs` — static RTK rewrite rules: regex patterns, equivalent `rtk` commands, rewrite prefixes, categories, savings percentages, and per-subcommand status/savings.

As a whole, `src/discover/` scans AI coding sessions, extracts commands, classifies which commands RTK can optimize or rewrite, estimates savings, detects related agent integrations, and reports supported/unsupported opportunities.
