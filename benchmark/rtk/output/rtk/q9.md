## `gh` subcommands rtk intercepts (from `src/cmds/git/gh_cmd.rs`)

### Top-level `run()` dispatch (L199–L209)

| `gh` subcommand | rtk behavior |
|----------------|--------------|
| `pr` | Routes to `run_pr()` — structured PR operations |
| `issue` | Routes to `run_issue()` — structured issue operations |
| `run` | Routes to `run_workflow()` — workflow run operations |
| `repo` | Routes to `run_repo()` — repo view |
| `api` | **Passthrough** (explicit comment: "Converting JSON to a schema destroys all values and forces Claude to re-fetch") |
| `_` (unknown) | Passthrough via `run_passthrough("gh", subcommand, args)` |

**Note:** If `--json` flag is in args, ALL subcommands immediately passthrough (L194–196).

### `run_pr()` dispatch (L217–L228)

| `gh pr <sub>` | rtk behavior |
|---------------|--------------|
| `list` | `list_prs()` — fetches `--json number,title,state,author,updatedAt`, formats compact PR list (capped at `CAP_LIST`) |
| `view` | `view_pr()` — fetches full PR JSON, formats with body filtering via `filter_markdown_body()` |
| `checks` | `pr_checks()` — structured check-run status |
| `status` | `pr_status()` — compact PR status summary |
| `create` | `pr_create()` — passthrough-style with tracking |
| `merge` | `pr_merge()` — passthrough-style with tracking |
| `diff` | `pr_diff()` — compact diff output |
| `comment` | `pr_action("commented", ...)` — passthrough action |
| `edit` | `pr_action("edited", ...)` — passthrough action |
| `_` | Passthrough |

### `run_issue()` dispatch (L589–L593)

| `gh issue <sub>` | rtk behavior |
|----------------|--------------|
| `list` | `list_issues()` — fetches `--json number,title,state,author`, compact list |
| `view` | `view_issue()` — full issue JSON formatted with `filter_markdown_body()` |
| `_` | Passthrough |

### `run_workflow()` dispatch (L712–L716)

| `list` | `list_runs()` — compact workflow run list |

| `_` | Passthrough |

### `run_repo()` (L842–L861)

| `gh repo <sub>` | rtk behavior |
|----------------|--------------|
| `view` (or empty) | Fetches `--json name,owner,description,url,stargazerCount,forkCount,isPrivate`, formats compact repo summary |
| any other subcommand | Passthrough |

### `run_api()` (L982–L987)

`gh api` is **always passed through verbatim** with this comment:
> `// gh api is an explicit/advanced command — the user knows what they asked for.`
> `// Converting JSON to a schema destroys all values and forces Claude to re-fetch.`
> `// Passthrough preserves the full response and tracks metrics at 0% savings.`
