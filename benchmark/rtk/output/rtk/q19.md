### PR Number and Title
PR #10 — `feat: add GitHub CLI integration (depends on #9)`

### Motivation
PR #10 introduced `rtk gh` (GitHub CLI wrapper) with a **two-level optimization system**:

- **Level 1 (default)**: Conservative filtering — removes counters in headers, `@` prefixes, compacts merge status; 12–18% additional savings with zero UX loss.
- **Level 2 (flag `-u` / `--ultra-compact`)**: More aggressive — ASCII icons instead of emoji (`🟢 → "O"`, `🟣 → "M"`), inline check format (`"Checks: 3/3 passed" → "✓3/3"`), compact headers (`"Pull Requests" → "PRs"`); 22% additional total savings.

The flag was introduced to let users explicitly opt into more aggressive output compression when they need maximum token savings and are willing to trade some readability.

Validated token savings: `rtk gh pr view` — 87% reduction; `rtk gh run list` — 82%; `rtk gh pr checks` — 79%.

### Commands Updated by PR #10
All the initial `rtk gh` subcommands were introduced in this PR:
- `rtk gh pr list/view/checks/status` — PR management (53–87% reduction)
- `rtk gh issue list/view` — Issue tracking (26% reduction)
- `rtk gh run list/view` — Workflow monitoring (82% reduction)
- `rtk gh repo view` — Repository info (29% reduction)

### Note on `-u` alias
PR #1188 (`fix(git): remove -u short alias from --ultra-compact to fix git push -u`) later removed the `-u` short alias specifically because it conflicted with `git push -u` (set upstream). The long form `--ultra-compact` was retained.
