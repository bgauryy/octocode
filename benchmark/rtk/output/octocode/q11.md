### 1. PR Number and Title

**PR #10** — "feat: add GitHub CLI integration (depends on #9)"

The `--ultra-compact` / `-u` global flag was introduced in `src/main.rs` as part of this PR:

```rust
/// Ultra-compact mode: ASCII icons, inline format (Level 2 optimizations)
#[arg(short = 'u', long, global = true)]
ultra_compact: bool,
```

---

### 2. Stated Motivation

The PR description (in French) describes a "Système d'Optimisation à Deux Niveaux" (Two-Level Optimization System):

**Level 1 (Conservative — Default)**:
- Removes counters from headers: `"Pull Requests (3)"` → `"Pull Requests"`
- Removes `@` prefix: `"@user"` → `"user"`
- Compact mergeable status: `"MERGEABLE"` → `"✓"`, `"CONFLICTING"` → `"✗"`
- Result: +12-18% savings, zero UX loss

**Level 2 (Moderate — Flag `-u` / `--ultra-compact`)**:
- ASCII icons instead of emoji: 🟢 → `"O"`, 🟣 → `"M"`, 🔴 → `"C"`
- Inline check format: `"Checks: 3/3 passed"` → `"✓3/3"`
- Compact headers: `"Pull Requests"` → `"PRs"`, `"Workflow Runs"` → `"Runs"`
- Result: +22% additional savings on PR view (87% total)

The motivation was achieving maximum token savings for constrained contexts where even emoji characters cost tokens, validated on a production repository (`methode-aristote/app`).

### 3. Commands Updated to Support `--ultra-compact`

The following `gh` subcommands were wired to receive the `ultra_compact: bool` parameter in PR #10:

| Command | Ultra-compact change |
|---|---|
| `gh pr list` | Header: `"📋 Pull Requests"` → `"PRs"` |
| `gh pr view` | State icons: emoji → ASCII (`O`/`M`/`C`) |
| `gh pr checks` | Compact check counts |
| `gh pr status` | Compact format |
| `gh issue list` | Compact icons |
| `gh run list` | Header: `"🏃 Workflow Runs"` → `"Runs"`; icons: emoji → ASCII (`✓`/`✗`/`X`/`~`) |
| `gh repo view` | (wired but `_ultra_compact` unused in initial PR) |

The flag was defined as `global = true`, meaning it applies to all subcommands when set at the top level (e.g., `rtk -u gh pr list`).
