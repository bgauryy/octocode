## `src/discover/` — 7 files

### Overall Module Responsibility
`//! Scans AI coding sessions to find commands that could benefit from RTK filtering.`

Two jobs: (1) **real-time command rewriting** — every LLM agent hook calls `rtk rewrite "..."` and this module decides whether to rewrite it; (2) **history analysis** — `rtk discover` scans past LLM sessions to find commands that could have been rewritten but weren't.

### File-by-File Purpose

| File | Module doc comment / Purpose |
|---|---|
| `mod.rs` | `//! Scans AI coding sessions to find commands that could benefit from RTK filtering.` — Re-exports the module; exposes `lexer`, `provider`, `registry`, `report`, `rules` |
| `lexer.rs` | (no `//!` doc comment) — Single-pass shell tokenizer that turns raw command strings into typed tokens (`TokenKind::Arg`, `Operator`, `Pipe`, etc.); understands shell quoting, escapes, redirects. Critical for compound command splitting. ~1308 lines |
| `rules.rs` | (no `//!` doc comment) — Static catalog of 60+ rewrite rules (`RtkRule` structs with `pattern`, `rtk_cmd`, `rewrite_prefixes`, `category`, `savings_pct`, `subcmd_savings`, `subcmd_status`). Compiled into a `RegexSet` at first use via `lazy_static`. ~936 lines |
| `registry.rs` | `//! Matches shell commands against known RTK rewrite rules to decide how to handle them.` — Rewrite engine that uses the lexer and rules; handles compound splitting, env prefix stripping, path normalization, guard conditions (`RTK_DISABLED`, `--json`, etc.) |
| `provider.rs` | `//! Reads Claude Code session logs from disk and streams their command history.` — `SessionProvider` trait + Claude Code JSONL implementation; reads `~/.claude/` session files to extract tool_use commands |
| `report.rs` | `//! Data types for reporting which commands RTK can and cannot optimize.` — `RtkStatus` enum and aggregation types used by `rtk discover` output |
| `README.md` | Human-readable documentation covering the full rewrite pipeline, tokenization algorithm, guard conditions, and how to add new rewrite rules |
