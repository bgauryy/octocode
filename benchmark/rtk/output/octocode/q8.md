### File: `src/hooks/init.rs`
- **Path**: `src/hooks/init.rs`
- **Line count**: 6,838 lines

### Purpose

From the module doc comment:
```
//! Sets up RTK hooks so AI coding agents automatically route commands through RTK.
```

This file is the **hook installation and lifecycle management engine** for all supported AI coding agents. It handles:

1. **Multi-agent hook setup** — Configures hooks for every supported AI coding environment:
   - Claude Code (`.claude/settings.json`, hooks.json)
   - Cursor
   - Gemini CLI
   - GitHub Copilot
   - Codex
   - OpenCode (TypeScript plugin)
   - Pi coding agent (TypeScript extension)
   - Hermes
   - and others

2. **Hook file generation** — Writes/installs the hook scripts, plugin files, and configuration JSON that make agents intercept tool calls and automatically rewrite commands through `rtk rewrite`

3. **Embedded content** — Uses `include_str!()` to embed the OpenCode TypeScript plugin and Pi extension at compile time

The file is large because it contains installation logic, template generation, and configuration JSON for many different AI coding agents, each with their own plugin format.
