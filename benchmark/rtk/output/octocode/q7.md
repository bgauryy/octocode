## Module purpose (from README.md)

The `src/discover/` module has two jobs:

1. **Rewrite commands** — Every LLM agent hook calls `rtk rewrite "git status"`. This module decides whether to rewrite it (`rtk git status`) or pass it through unchanged. This is the hot path — every command the LLM runs goes through here.

2. **Analyze history** — `rtk discover` scans past LLM sessions to find commands that *could have been* rewritten but weren't. Same classification logic, different consumer.

The classification logic is **shared** between discover and rewrite — same patterns, same rules, different consumers.

### How it works (summary from README):

1. **Tokenization** (`lexer.rs`): Turns raw shell strings into typed tokens — understands quoting, escapes, redirects, operators
2. **Compound splitting** (`mod.rs`): Splits on `&&`, `||`, `;`, `|`; rewrites each segment independently
3. **Per-segment rewriting**: Strip redirects → short-circuit specials → classify (via `registry.rs` + `rules.rs`) → apply rewrite
4. **History analysis** (`provider.rs` + `report.rs`): Reads Claude Code JSONL sessions, classifies past commands, generates adoption reports
