## What `src/discover/` Is Responsible For

The module has **two primary jobs**:

### 1. Live Command Rewriting (hot path)
Every LLM agent hook calls `rtk rewrite "git status"`. The module:
1. **Tokenizes** the raw shell string using `lexer.rs` (handling `&&`, `||`, `;`, pipes, quotes)
2. **Splits** compound commands into segments (each side of `&&`/`||`/`;` is rewritten independently; only the left side of pipes)
3. **Classifies** each segment by stripping env prefixes/sudo, normalizing paths, and matching against 60+ patterns in `rules.rs`
4. **Rewrites** matching commands: replaces the command prefix with `rtk <cmd>`, re-prepends env prefixes, re-appends redirects

Result: `cargo fmt --all && cargo test 2>&1 | tail -20` → `rtk cargo fmt --all && rtk cargo test 2>&1 | tail -20`

Several guards skip rewriting (e.g., `RTK_DISABLED=1`, `gh --json`, `cat` with write operations, commands in `hooks.exclude_commands`).

### 2. History Analysis (`rtk discover`)
Reads past Claude Code JSONL session files, extracts all commands run, runs them through the same classification logic, and produces a report of: which commands could have been rewritten, estimated token savings, and adoption rate.

**The classification logic is shared between live rewriting and history analysis** — same patterns, same rules, different consumers.
