## npm Package Named "rtk"

The npm package named `rtk` is **NOT** related to `rtk-ai/rtk` (the Rust Token Killer). It is a completely different project:

| Field | Value |
|---|---|
| **Name** | `rtk` |
| **Version** | 4.2.0 |
| **Description** | "Agnostic software release tool for managing versions on changelog (keep-a-changelog), multi-format files (JSON, Makefile, text, TOML, YAML), and also for tagging source code of a Git repo" |
| **Author / Owner** | cliffano |
| **Repository** | https://github.com/cliffano/rtk |
| **npm URL** | https://www.npmjs.com/package/rtk |
| **Last Published** | 2025-11-28T22:19:40.671Z |
| **Main Entry** | ./lib/rtk |

The `rtk` npm package is a JavaScript release management tool by `cliffano` that handles changelog updates (keep-a-changelog format), version bumping in multiple file formats (JSON, Makefile, text, TOML, YAML), and Git repository tagging.

**Note**: The `rtk-ai/rtk` (Rust Token Killer) project is a Rust binary with no npm package. The two projects share only the `rtk` name.
