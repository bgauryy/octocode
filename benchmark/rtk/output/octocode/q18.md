## Naming conflict risk assessment

**Low practical risk, but clear namespace collision:**

- The npm `rtk` package is an established release tool by a different author with its own purpose
- `rtk-ai/rtk` is a Rust CLI binary distributed via `cargo install` or Homebrew — it is NOT published on npm
- Weekly downloads for the npm `rtk` are low (1,912) suggesting a niche tool, reducing confusion
- Since `rtk-ai/rtk` is not on npm, there is no direct distribution conflict today

**Risk would arise if** `rtk-ai/rtk` ever wanted to publish to npm under the name `rtk` — the name is taken and would require using `@rtk-ai/rtk` or a different name.
