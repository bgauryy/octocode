## Answer

From `src/core/README.md`, the TOML filter pipeline applies **8 stages in order**:

1. **`strip_ansi`** — Remove ANSI escape codes (if enabled)
2. **`replace`** — Line-by-line regex substitutions (chainable, supports backreferences)
3. **`match_output`** — Short-circuit rules: if output matches a pattern, return a message; the `unless` field prevents swallowing errors
4. **`strip_lines` / `keep_lines`** — Filter lines by regex (mutually exclusive with each other)
5. **`truncate_lines_at`** — Truncate each line to N chars (unicode-safe)
6. **`head_lines` / `tail_lines`** — Keep first N or last N lines (with omit message)
7. **`max_lines`** — Absolute line cap applied after head/tail
8. **`on_empty`** — Return a message if the result is empty after all previous stages

**Three-tier filter lookup** (first match wins):
1. `.rtk/filters.toml` (project-local, requires `rtk trust`)
2. `~/.config/rtk/filters.toml` (user-global)
3. Built-in filters concatenated by `build.rs` at compile time
