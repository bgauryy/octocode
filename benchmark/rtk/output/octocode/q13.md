# Q13 — Full diff filter in `src/cmds/git/diff_cmd.rs`

## What `diff_cmd.rs` implements

`diff_cmd.rs` implements **two distinct diff modes**, neither of which is a direct pass-through filter for `git diff` output in the traditional sense:

### Mode 1: `run(file1, file2)` — Custom two-file comparison

Compares two files directly (not from git). Uses rtk's own `compute_diff()` algorithm (line-by-line comparison with a similarity threshold for "modified" vs "added+removed").

**Output format:**
```
file1.rs → file2.rs
 +N added, -M removed, ~P modified

+   1 <added line>
-   5 <removed line>
~  10 <old content> → <new content>
```

### Mode 2: `run_stdin()` — Unified diff condenser

Reads a unified diff (e.g., from `git diff` piped via stdin) and condenses it via `condense_unified_diff()`.

---

## 1. What parts of a `git diff` output does rtk keep?

In `condense_unified_diff()`:
- **File path** (from `+++ b/path` lines) → `[file] path (+N -M)` header
- **Added lines** (lines starting with `+`, excluding `+++`)
- **Removed lines** (lines starting with `-`, excluding `---`)

## 2. What parts does it strip or compress?

Stripped entirely:
- **Hunk headers** (`@@ -n,m +n,m @@ func_name`) — dropped completely
- **`diff --git a/... b/...`** lines
- **`--- a/...`** lines
- **Context lines** (lines without `+`/`-` prefix) — stripped entirely

Compressed:
- When total changes per file exceed 10: adds an `  ... +{N} more` annotation line (but still shows all lines before it — the annotation is informational only)

## 3. Maximum context lines preserved per hunk

**Zero context lines** are preserved. The `condense_unified_diff()` function only collects lines starting with `+` or `-`. All context lines (unchanged lines shown for context in standard unified diffs) are silently dropped.

There is no "per hunk" concept in rtk's filter — it processes the entire diff per file, aggregating all `+` and `-` lines together without hunk boundaries.

The `... +{N} more` overflow annotation appears after 10 total added+removed lines, but this is just a note — all lines are still shown above it.
