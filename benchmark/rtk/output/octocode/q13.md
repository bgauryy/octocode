## Full Diff Filter in `src/cmds/git/diff_cmd.rs`

`src/cmds/git/diff_cmd.rs` (457 lines) implements two diff modes: **file-to-file comparison** (`run()`) and **unified diff via stdin** (`run_stdin()` → `condense_unified_diff()`).

---

### 1. What parts does rtk keep?

**File-to-file mode (`run()`):**
- A header line: `<file1> → <file2>`
- A summary line: `   +N added, -N removed, ~N modified`
- Each changed line formatted as:
  - `+NNNN <content>` (added line)
  - `-NNNN <content>` (removed line)
  - `~NNNN <old> → <new>` (modified line, when Jaccard similarity > 0.5)
- `[ok] Files are identical` if no differences

**Unified diff stdin mode (`run_stdin()` / `condense_unified_diff()`):**
- File header compressed to: `[file] <path> (+N -N)`
- **All `+` (added) and `-` (removed) lines in their entirety** — the source has an explicit comment:
  > "Never truncate diff content — users make decisions based on this data. Only strip diff metadata (headers, @@ hunks); all +/- lines shown in full."
- An `... +N more` indicator appended after the changes *if* total changed lines exceed 10 (but all lines are still emitted before the indicator)

---

### 2. What parts does it strip or compress?

**File-to-file mode:**
- Context lines (unchanged lines between changes) — not shown at all
- No additional stripping

**Unified diff stdin mode (`condense_unified_diff()`):**
- `diff --git a/... b/...` header lines → dropped
- `--- a/<file>` lines → dropped (replaced by `[file]` prefix)
- `+++ b/<file>` lines → consumed to build compact `[file]` header
- `@@ -L,N +L,N @@ ...` hunk headers → dropped entirely
- Context lines (unchanged lines, no `+`/`-` prefix) → dropped

---

### 3. Maximum context lines preserved per hunk

**Zero (0).** The `condense_unified_diff` function explicitly drops all context lines — only `+`-prefixed and `-`-prefixed lines are kept. The code:

```rust
} else if line.starts_with('+') && !line.starts_with("+++") {
    added += 1;
    changes.push(line.to_string());
} else if line.starts_with('-') && !line.starts_with("---") {
    removed += 1;
    changes.push(line.to_string());
}
// All other lines (context, @@ headers) fall through and are dropped
```

No context lines are collected or emitted. This is the "ultra-condensed diff" philosophy stated in the module doc: `/// Ultra-condensed diff - only changed lines, no context`.
