## 2. Original design rationale (from PR description)

The PR replaced bash-based hook scripts with a native binary hook engine:

> "From the idea of #536 to implement with current code structure and standardize with codebase (no duplication/divided flow)"

**Key design decisions:**
- **Binary over bash**: Replace 4 bash hook scripts (890 lines deleted) with native `rtk hook claude | cursor | copilot | gemini` Rust handlers
- **Protocol-native handling**: Each AI agent has its own JSON protocol (Claude Code: `tool_name/tool_input/updatedInput`, Copilot: VS Code JSON + CLI string, Cursor/Gemini: dedicated handlers)
- **Permission system**: Built-in verdict engine (Ask/Allow/Deny/Default) loading rules from Claude Code settings.json — no external permission tool needed
- **Streaming infrastructure**: New `FilterMode` and `StdinMode` enums for unified execution; `ChildGuard` RAII for zombie process prevention
- **Auto-migration**: `rtk init` migrates legacy bash hook scripts to binary automatically

**Breaking change noted in PR body:**
> "For claude code user, they'll need to re-install with 'rtk init -g', because claude code now use native binary instead of rewrite. Old script supported until June 13th 2026"
