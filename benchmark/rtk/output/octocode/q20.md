| Job | Needs | What it does |
|---|---|---|

| `clippy` | `fmt` | `cargo clippy --all-targets` (lint gate) |

| `security` | `clippy` | Three-phase scan: (1) `cargo audit` CVE check, (2) critical files check (`runner.rs`, `init.rs`, `Cargo.toml`, `workflows/*.yml`), (3) dangerous-patterns scan for `Command::new("sh")`, `unsafe {`, `.unwrap()`, `reqwest::`, network types, etc. Reports to `$GITHUB_STEP_SUMMARY` |
| `semgrep` | `clippy` | `semgrep scan --config .semgrep.yml --baseline-commit <base_sha> --error` inside `semgrep/semgrep` Docker container |
| `benchmark` | `clippy` | Builds `rtk --release`, installs Python (ruff/pytest/mypy) and Go (golangci-lint) tools, runs `./scripts/benchmark.sh` |
| `doc-review` | — | **Develop PRs only** (`github.base_ref == 'develop'`). Gathers PR diff + title/body, calls Claude API (`claude-sonnet-4-6`) with a structured JSON schema response asking for PASS/FAIL + reasoning. Fails CI if AI verdict is FAIL. Skipped if `RTK_DOCS_ANTHROPIC_KEY` secret not set. |
