## Q19: PR Introducing `--ultra-compact` / `-u` Flag

### Findings from octocode research

**The exact introducing PR could not be pinpointed via `githubSearchPullRequests`** (keyword search returned only the most recent PRs, not historical ones). However, the following evidence was gathered:

### What is confirmed via code + CHANGELOG:

**Current flag definition** (`src/main.rs`, lines 69–71):
```rust
/// Ultra-compact mode: ASCII icons, inline format (Level 2 optimizations)
#[arg(long, global = true)]
ultra_compact: bool,
```

**Original flag definition** (per `docs/contributing/ARCHITECTURE.md` v3.1, last updated 2026-03-24, at `main.rs:51-53`):
```rust
#[arg(short = 'u', long, global = true)]
ultra_compact: bool,
```

So the original flag included a `-u` short alias. The short alias was **removed** (commit `6b76fdb`) to fix a conflict with `git push -u` (upstream tracking), referenced as issue **#1086**. This removal appeared in the CHANGELOG "Unreleased" section before v0.35.0 (April 2026).

### Motivation
The ARCHITECTURE.md describes the feature as "Level 2 optimizations": ASCII icons instead of words, inline format, maximum compression for LLM contexts. Example: `✓ PR #42 merged` (ultra-compact) vs `Pull request #42 successfully merged` (normal).

### Commands Updated
Ultra-compact mode (`ultra_compact: bool`) flows through `main.rs` → `cli.ultra_compact` and is forwarded to:
- **`src/cmds/git/gh_cmd.rs`**: `run()`, `run_pr()`, `run_issue()`, `run_workflow()`, `run_repo()`, `list_prs()`, `view_pr()`, `pr_checks()`, `pr_status()`
- **`src/cmds/git/glab_cmd.rs`**: `run()`, `pipeline_icon()`, `state_icon()`, `run_mr()`

`glab` support was added in v0.38.0 (2026-04-29, closes #851), so the ultra-compact flag was already in the codebase before glab; `glab` integration adopted it on arrival.

The feature was introduced before v0.33.0 (2026-03-24) and the short `-u` form was removed around v0.36.0–v0.37.0.
