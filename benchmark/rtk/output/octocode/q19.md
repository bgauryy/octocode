# Q19 — The PR that introduced `--ultra-compact` / `-u`

## 1. PR Number and Title

**PR #10** — "feat: add GitHub CLI integration (depends on #9)"

- Merged: 2026-01-29
- Target branch: master
- URL: https://github.com/rtk-ai/rtk/pull/10

## 2. Stated Motivation

The PR introduced a **two-level optimization system** for the new `rtk gh` command:

**Level 1 (Conservative — Default)**:
- Removes counters from headers: "Pull Requests (3)" → "Pull Requests"
- Removes `@` prefix: "@user" → "user"
- Compact mergeable status: "MERGEABLE" → "✓", "CONFLICTING" → "✗"
- Result: +12-18% savings, zero UX loss

**Level 2 (Moderate — `-u` / `--ultra-compact` flag)**:
- ASCII icons instead of emoji: 🟢 → "O", 🟣 → "M", 🔴 → "C"
- Inline checks format: "Checks: 3/3 passed" → "✓3/3"
- Compact headers: "Pull Requests" → "PRs"
- Result: +22% extra savings on PR view (87% total)

The flag was added to provide an extra layer of token reduction beyond the default compact output, specifically optimizing output for LLM contexts.

## 3. Commands Updated to Support It

The PR added the `--ultra-compact` global flag via `ultra_compact: bool` in the `Cli` struct and wired it through the new `rtk gh` command integration. Commands updated:

- **`rtk gh pr list/view/checks/status`** — PR management (53–87% token reduction)
- **`rtk gh issue list/view`** — Issue tracking (26% reduction)
- **`rtk gh run list/view`** — Workflow monitoring (82% reduction)
- **`rtk gh repo view`** — Repository info (29% reduction)

**Files changed:**
- `src/main.rs` — Added `ultra_compact: bool` field to `Cli` struct and `Commands::Gh` routing
- `src/gh_cmd.rs` — New module (584 lines) implementing all `gh` command handlers with ultra-compact support
- `CLAUDE.md` — Documentation update
- `.github/workflows/benchmark.yml` — CI update

**Note:** The `-u` short alias was later removed in v0.35.0 (PR #1188, merged 2026-04-13) to fix a conflict with `git push -u` upstream tracking (issue #1086). The long form `--ultra-compact` remains functional.
