### `api` Handler (`run_api()`, line 982)

Always passthrough. Source comment:
> "gh api is an explicit/advanced command — the user knows what they asked for. Converting JSON to a schema destroys all values and forces Claude to re-fetch. Passthrough preserves the full response and tracks metrics at 0% savings."

### Summary

RTK intercepts **5 top-level `gh` subcommands** with custom formatting: `pr`, `issue`, `run`, `repo`. The `api` subcommand and all others are explicitly passed through raw.

Within `pr`, RTK provides custom formatting for `list`, `view`, `checks`, `status`, and `diff`. `create`, `merge`, `comment`, and `edit` pass through.

Within `issue`: `list` and `view` have custom formatting.

Within `run`: `list` and `view` have custom formatting.

Within `repo`: only `view` has custom formatting.
