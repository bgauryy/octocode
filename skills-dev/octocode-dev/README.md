# octocode-dev

Repo-internal skill for developing the Octocode monorepo: the task runner, the change pipeline (core contract, generated contract, native, interfaces), developer docs and tool-audit lanes. Not published. Entry point: [`SKILL.md`](SKILL.md).

Run `node skills-dev/octocode-dev/scripts/dev.mjs --help` for all repo tasks.

- [`scripts/`](scripts/README.md): task runner and helpers.
- [`docs/`](docs/DEVELOPMENT.md): [development](docs/DEVELOPMENT.md), [adding config](docs/ADDING_CONFIG.md), [tool quality bar](docs/TOOL_QUALITY.md), [scraping maintenance](docs/SCRAPING_MAINTENANCE.md).

User-facing docs live in `<repo>/docs/README.md`.
