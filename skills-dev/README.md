# skills-dev

Skills for working on this repository. They are not published and they are not part of the public install set.

| Tree | Role |
|---|---|
| [`skills/`](../skills/) | Public skills. Shipped with the CLI and the Pi bundle. |
| [`skills-beta/`](../skills-beta/) | Tested skills. In trial, not published. |
| `skills-dev/` | Local development of this monorepo. |

The folders here are `octocode-dev`, `rust-best-practices`, `ast-best-practices`, and `lsp-best-practices`.
