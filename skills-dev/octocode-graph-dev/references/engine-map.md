# Engine map

Paths are under `packages/octocode-native/crates/`. `ast_graph/` is `tool-graph/src/ast_graph/`, and every other path that does not start with a crate name is under `ast_graph/`. Rows follow the pipeline: extraction, scan and file linking, call resolution, projection, encoding, queries, CLI and MCP. Each module opens with a `//!` line naming its job.

| Change | Owner | Tests |
|---|---|---|
| What a file yields: declarations, imports, calls, receivers, arguments, macro bodies, test flags | `engine/src/signatures/graph_facts/` (a file per language, `receiver/`); scan and reuse in `engine/src/fact_scan/` | `engine/src/signatures/graph_facts/tests/`, `engine/src/fact_scan/tests/` |
| Which files are scanned, roles (test, generated, bundled), scope refusals and hints | `graph/scan.rs`, `classify.rs`, `graph/scope.rs` | `graph/tests/prune.rs`, `store/tests/limits.rs` |
| Import specifier to file: tsconfig paths, workspaces, Cargo, go.mod, Python roots, packages | `graph/resolve.rs`, `cargo.rs`, `packages.rs`, `linking.rs`; `tools-shared/src/import_resolution/` (one linking record per grammar; lspSearch places importers with it too) | `graph/tests/resolution.rs`, `link_tests/imports.rs` |
| Per-file linking: exports, re-exports, CommonJS | `graph/link.rs`, `graph/imports.rs`, `graph/exports.rs` | `link_tests/commonjs.rs`, `store/tests/reexports.rs` |

## Cache versions

Bump the constant whose cached data the change makes wrong and add a line to its version comment. A bump forces every rebuild, so a pure query change bumps none. Tests read the constants, so a bump needs no test edits.

| Constant | File | Bump when |
|---|---|---|
| `GRAPH_FACTS_SCHEMA_VERSION` | `engine/src/signatures.rs` | Extracted facts change for the same source |
| `ANALYSIS_VERSION` | `tool-graph/src/ast_graph.rs` | Persisted linking semantics change without a format change |
| `FORMAT_VERSION` | `ast_graph/store/format.rs` | The `graph.bin` encoding changes |

## Python standard-library list

`tools-shared/src/import_resolution/aliases/python_stdlib.txt` is committed and generated by [gen-python-stdlib.mjs](../scripts/gen-python-stdlib.mjs); the engine build reads it and never fetches. The script records the interpreter's `sys.stdlib_module_names` (it refuses a `python3` off its `PINNED_PYTHON` line; `--python PATH` picks another) and typeshed `stdlib/VERSIONS` at `TYPESHED_REF`, never `main`. To move a pin, change the constant, run the script and include the regenerated file in the change. [Its tests](../scripts/gen-python-stdlib.test.mjs) cover the header and the refusal: `node --test skills-dev/octocode-graph-dev/scripts/gen-python-stdlib.test.mjs`.
