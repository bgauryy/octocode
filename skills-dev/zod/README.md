# Zod skill

Create, review and test Zod v4 schemas. Start with [SKILL.md](SKILL.md), which routes each task to the relevant reference or focused rule. [output.md](output.md) owns delivery.

Baseline: TypeScript ^5.5 and Zod ^4.3.0; verify APIs against the project's installed version. No scripts or additional runtime setup are required by this skill.

The references cover parsing, schema composition, transforms, errors, architecture and testing. Focused rules retain examples for particular mistakes; load them only when that decision arises.
