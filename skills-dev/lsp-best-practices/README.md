# lsp-best-practices

Developer skill for building and using Language Server Protocol clients in the octocode monorepo: the Rust/tokio implementation and its tests, protocol, lifecycle, handles, coordinates, primitives, walks, readiness, per-server settings, efficiency, and agent usage of `lspSearch`.

Entry point: `SKILL.md` (mental model, numbered rules, routes). Depth lives in `references/`: one topic per file, loaded only when the current step needs it. `references/octocode-known-defects.md` and `references/octocode-rust-defects.md` hold the guards and regression tests for fixed engine defects, plus the open ones.
