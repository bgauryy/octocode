What am I seeing?

This is a read-only view of one workspace. Auto-refresh checks the database every 3 seconds; it does not mean agents are running. The four totals cover the whole workspace, regardless of filters.

Messages include retained history and inactive agents. Search matches message text, sender/target names, conversation or exact message ID. Other tabs search only the loaded page. Filters apply automatically; Older loads more records and pauses automatic row refresh.

Locks show live leases with live owners; use Records for retained lock events. Documents show publication metadata and file references, not file contents. Connections and Handoffs omit endpoint/token fields; Records retain original event metadata. Internal peer-directory caches are not entity views. Pruned records and other workspaces are not shown.

Handled means every recipient recorded completion; it does not prove correctness. Pending can include inactive recipients or expired messages. A submitted handoff is not a completion receipt. Unconfirmed handoffs need inspection before retrying.

Messages

History includes inactive agents and all retained messages in this workspace. Pruned records cannot be recovered here. A receipt records handling, not correctness. Locks coordinate cooperating agents; they are not an operating-system fence.
