# Q16 answer key — license headers behind a BOM (csharp / Newtonsoft.Json @ 52fa3ae)

| Fact | Value |
|---|---|
| .cs files directly in Src/Newtonsoft.Json/Converters/ | **18** |
| First line is `#region License` (BOM stripped) | **17** |
| Exception | `UnionConverter.cs`, first line `using System;` |
| BOM trap | only 1 of the 17 matches byte-exactly without stripping a BOM; 16 start with EF BB BF. A tool or grep that does not strip the BOM reports 1 instead of 17 |

Verified with a loop over `git -C packages/octocode-benchmark/local/repos/csharp ls-files 'Src/Newtonsoft.Json/Converters/*.cs'` (no subfolder paths), comparing `head -1 | sed 's/^\xEF\xBB\xBF//'` to `#region License` (17/18) and without the sed (1/18); `rg -l --encoding none '^\xEF\xBB\xBF'` lists the BOM files.
