## What ran

One pass over the 30-question GitHub v2 set with three isolated runner agents:

- `octocode` via `compare/bin/octoc1822` (`npx -y octocode@18.2.2 tools …`)
- `rtk` via `compare/bin/rtkm` (`rtk gh …`)
- `headroom` via `compare/bin/ghc` (`gh …` compressed by Headroom)

Two blind judges then graded pairwise packets:

- Octocode vs RTK
- Octocode vs Headroom
