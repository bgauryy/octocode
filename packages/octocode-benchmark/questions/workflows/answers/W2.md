How the main bug worked: at `8.1.7`, `get_help_option` (core.py:1291) built a new `Option(...)` with a nested
`show_help` on every call (1298, 1303). `Command.parse_args` calls it twice: through `self.make_parser(ctx)`
(8.1.8 line 1413), whose parser records `param_order`, and again through `self.get_params(ctx)` in
`iter_params_for_processing(param_order, ...)` (1416). `sort_key` uses `invocation_order.index(item)` (134), which
compares by identity. Because the two calls returned different objects, the help option was never found in the
invocation order and got `idx = inf` (136). So `--help` sorted after every other eager parameter, wherever the user
typed it. At `8.1.8` the method builds `HelpOption(help_options)` once and returns that same instance. `HelpOption`
is defined in `decorators.py:525–551`: `is_eager=True` at 540, the `show_help` callback at 547–551.
