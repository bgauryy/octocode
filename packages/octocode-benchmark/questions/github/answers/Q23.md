On the question's wording for step 3: at this SHA the wrapper `new_sync_write` is used when a file provides only `write_iter` (the iterator-based callback) and no `write`; `write` is the older-style member and is tried first. An answer that describes this order correctly is right even though the question words it the other way round; an answer that says "`new_sync_write` wraps `->write`" is wrong.
