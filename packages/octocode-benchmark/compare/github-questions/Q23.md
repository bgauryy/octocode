# Q23 — Linux write() syscall to VFS dispatch flow

**id:** `gh-linux-write-syscall-vfs-flow`

## Question

In `torvalds/linux`, trace the kernel path taken by a userspace `write(2)` call
from its syscall entry down to the filesystem/driver method that receives the
data, and explain **each step** in order. Specifically:

1. Name the macro and file that define the `write` syscall entry point.
2. Name the intermediate helper it calls that resolves the file descriptor, and
   the core VFS function that helper invokes.
3. In that core VFS function, explain how it decides which file-operation to
   call — i.e. the `file_operations` member(s) it dispatches to and the wrapper
   used when only the older-style callback is available.
4. State what permission/position checks the VFS function performs before
   dispatching.

Cite the file for each step and quote the specific line that proves the call
from one step to the next.
