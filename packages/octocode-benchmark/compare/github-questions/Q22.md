# Q22 — Axios release-range compare

**id:** `gh-axios-tag-compare-range`

## Question

In `axios/axios`, use commit comparison between the release tags
`v1.18.0` and `v1.19.0` (base `v1.18.0`, head `v1.19.0`). Report the ahead/behind
commit counts for that range, then identify one commit in the range that changed
a file under `lib/` and cite its SHA together with the diff hunk that proves the
change — not the commit title. Explain how the range-comparison result differs
from reading that single commit's diff on its own.
