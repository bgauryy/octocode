# G13 reference
## Question
Which GitHub repository hosts the Prometheus project's official exporter for machine-level (host) metrics, and in its v1.8.2 release, what listen address, metrics path and maximum number of parallel scrape requests does it use by default?

## Key facts (graded)
1. Repository: `prometheus/node_exporter` ("Exporter for machine metrics"). Its tag `v1.8.2` is an annotated tag that points to commit `f1e0e8360aa60b6cb5e5cc1560bed348fc2c1895`. — evidence: `gh api repos/prometheus/node_exporter --jq .description`; `gh api repos/prometheus/node_exporter/git/tags/38885412845832eca3d4512dcc4ac535ca1190e7 --jq .object.sha`
2. Default listen address `:9100`, set through the exporter-toolkit flags: `kingpinflag.AddFlags(kingpin.CommandLine, ":9100")`. — evidence: `node_exporter.go:179` @ v1.8.2
3. Default metrics path `/metrics` (flag `web.telemetry-path`, `.Default("/metrics")`). — evidence: `node_exporter.go:160-163` @ v1.8.2
4. Default maximum parallel scrape requests `40` (flag `web.max-requests`, "Use 0 to disable", `.Default("40")`). — evidence: `node_exporter.go:168-171` @ v1.8.2

## Acceptable variations
- Writing the address as "port 9100 on all interfaces" or `0.0.0.0:9100`.
- Giving the flag names (`--web.listen-address`, `--web.telemetry-path`, `--web.max-requests`) in addition to the values.
- Mentioning other defaults from the same block (for example `runtime.gomaxprocs` default 1, `collector.disable-defaults` false) is fine.
- Line numbers ±3.

## Common wrong answers
- Naming a different repository (for example `prometheus/prometheus`, `prometheus/client_golang`, or a third-party fork).
- Stating a default for `web.max-requests` other than 40, or saying it is unlimited by default.
- Answering from a different release or the default branch without checking v1.8.2.
