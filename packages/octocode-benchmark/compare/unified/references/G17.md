## Question
For the PyPI release requests==2.32.3: which Python versions and runtime dependencies (including optional extras) does it declare, where is its source for that release, and what connection-pool and retry defaults does its HTTP adapter use?

## Acceptable variations
- Writing the dependencies in PyPI's normalized form (`charset-normalizer<4,>=2`, …) or quoting the `setup.cfg` `requires-dist` block.
- Omitting `DEFAULT_POOL_TIMEOUT`.
- Line numbers ±3.

## Common wrong answers
- Giving the dependency set or Python floor of a different release (for example `>=3.7`, or `chardet` as a hard dependency).
- Saying the adapter retries failed connections by default (default is 0 retries, read retries disabled).
- Pool size other than 10 for either `pool_connections` or `pool_maxsize`.
