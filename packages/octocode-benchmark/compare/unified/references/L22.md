## Question

The other `static` functions are `django/conf/urls/static.py:10` `static(prefix, view=serve, **kwargs)` (URL patterns for debug serving) and `django/template/context_processors.py:76` `static(request)` (adds `STATIC_URL`).
2. Callers in `django/` (exactly three call sites, two modules, each with `from django.templatetags.static import static`):
   - `django/forms/widgets.py:121` — `MediaAsset.path` property (class at line 67): returns `static(self._path)` unless the path starts with `http://`, `https://` or `/` (import at `widgets.py:13`);

   - `django/contrib/admin/templatetags/admin_list.py:187` — `_boolean_icon(field_val)`: `static("admin/img/icon-%s.svg" % …)` for yes/no/unknown icons (import at `admin_list.py:24`).
3. Not callers of this function: `django/contrib/staticfiles/urls.py:14` (`static(prefix, view=serve)` calls the URL-pattern helper imported from `django.conf.urls.static`, line 2); `django/conf/urls/static.py:15-19` (docstring example of the URL helper); `django/contrib/staticfiles/views.py:13` (`from django.views import static` imports a module); the `{% static %}` tag function `do_static` (`templatetags/static.py:156-171`) uses `StaticNode.handle_token`, not `static()`.
