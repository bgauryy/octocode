## Key facts (graded)
1. Rule: `CompilerOptions.GetResolveJsonModule()` returns the explicit tristate if set (`ResolveJsonModule != TSUnknown` → `== TSTrue`); otherwise true when the emit module kind is `node20` or `nodenext` (a TODO notes node16/node18 are not yet included), else true iff module resolution is `bundler`. 3. Indirectly: the file loader's `resolveImportsAndModuleAugmentations` only adds the resolved file to the program when this diagnostic is nil (`shouldAddFile`), and the checker's `resolveExternalModule` reports it as an error. — evidence: `tsc/internal/module/util.go:125`, `util.go:140-145`, `util.go:173-174`, `tsc/internal/compiler/fileloader.go:922-923`, `tsc/internal/checker/checker.go:15463-15467`, `checker.go:15661-15662`
