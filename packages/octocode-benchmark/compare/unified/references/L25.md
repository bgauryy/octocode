# L25 reference
## Question
In lodash/lodash at commit 2b5e6f7399, how does deep equality comparison (as used by `_.isEqual`) avoid infinite recursion when the compared values contain references back to themselves, and when does it consider two such self-referencing values equal?

## Key facts (graded)
1. Path: `isEqual(value, other)` (`lodash.js:11630`) → `baseIsEqual` (`lodash.js:3314`) → `baseIsEqualDeep` (`lodash.js:3338`), which lazily creates a `Stack` (`stack || (stack = new Stack)`) and passes it to `equalArrays`, `equalByTag` or `equalObjects`. The stack maps each value under comparison to its counterpart. — evidence: `lodash.js:3338-3380` (stack creation at 3359, 3372, 3379)
2. Arrays: `equalArrays` (`lodash.js:5706`) first looks up both values: `var arrStacked = stack.get(array); var othStacked = stack.get(other); if (arrStacked && othStacked) { return arrStacked == other && othStacked == array; }` ("Check that cyclic values are equal"). Otherwise it records the pair in both directions (`stack.set(array, other); stack.set(other, array);`), recurses, and removes both entries afterwards (`stack['delete'](array)`, `stack['delete'](other)`). — evidence: `lodash.js:5714-5725`, `lodash.js:5763-5764`
3. Objects: `equalObjects` (`lodash.js:5863`) does the same after the key checks: both values stacked → equal only if each is mapped to the other; then `stack.set` both ways and `stack['delete']` both at the end. — evidence: `lodash.js:5880-5888`, `lodash.js:5923-5924`
4. Maps and sets (`equalByTag`, `mapTag`/`setTag`): only `object` is checked — `var stacked = stack.get(object); if (stacked) { return stacked == other; }` ("Assume cyclic values are equal") — then it sets `COMPARE_UNORDERED_FLAG`, records `stack.set(object, other)`, compares the converted arrays with `equalArrays`, and deletes the entry. — evidence: `lodash.js:5819-5840`
5. Equality rule: when the recursion reaches a pair that is already being compared, the result is "equal" exactly when that pair is the same pairing as before (each side is mapped to the other); this stops the recursion and treats structurally identical cycles as equal, while cycles that pair up differently are unequal.

## Acceptable variations
- Line numbers ±3.
- Calling `Stack` a map/cache of visited pairs.
- Mentioning that `baseIsEqual` short-circuits identical values (`value === other`) before deep comparison.

## Common wrong answers
- Claiming lodash uses a depth limit or catches a stack-overflow error.
- Claiming a value is equal as soon as one side is seen again (for arrays and objects both sides must be on the stack and paired with each other).
- Pointing to the cloning code (`baseClone`, around `lodash.js:2715`) as the equality cycle check.
