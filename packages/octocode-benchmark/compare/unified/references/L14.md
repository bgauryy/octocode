# L14 reference
## Question
In lodash/lodash at commit 2b5e6f7399, how does `debounce` decide when to call the wrapped function, including what the `maxWait` option does?
## Key facts (graded)
1. `debounce` is in `lodash.js` (`function debounce(func, wait, options)`, line 10403). Defaults: `leading = false`, `trailing = true`, no maxWait. `maxing = 'maxWait' in options` (10421) and `maxWait = nativeMax(toNumber(options.maxWait) || 0, wait)` (10422): maxWait is never smaller than `wait`.
2. Each call to `debounced` (10499) records `lastArgs`/`lastThis`/`lastCallTime` and asks `shouldInvoke` (10455): invoke when it is the first call (`lastCallTime === undefined`), when `timeSinceLastCall >= wait`, when the clock went backwards (`timeSinceLastCall < 0`), or when `maxing && timeSinceLastInvoke >= maxWait` (10462).
3. With no pending timer, `leadingEdge` (10436) sets `lastInvokeTime`, starts the trailing timer (`setTimeout(timerExpired, wait)`), and invokes only if `leading`.
4. `timerExpired` (10466) re-checks `shouldInvoke`; if not yet due it re-arms with `remainingWait` (10445) = `min(wait - timeSinceLastCall, maxWait - timeSinceLastInvoke)` when maxing, else `wait - timeSinceLastCall`. When due, `trailingEdge` (10475) invokes only if `trailing && lastArgs` (10480), i.e. there was a call since the last invocation.
5. maxWait: calls in a tight loop with maxing on re-arm the timer and invoke immediately once maxWait has elapsed (10512 branch), guaranteeing an invocation at least every maxWait ms.
6. `cancel` (10487) clears the timer and resets state; `flush` (10495) invokes the pending trailing call immediately. `throttle` (10996) is `debounce` with `maxWait: wait` (11009) and `leading` defaulting to true.
## Acceptable variations
- Describing maxWait's guarantee without naming the tight-loop branch.
- Line numbers within a few lines.
## Common wrong answers
- Saying debounce invokes on the leading edge by default.
- Saying maxWait can be shorter than wait.
- Saying the trailing call fires even when there were no calls during the wait.
