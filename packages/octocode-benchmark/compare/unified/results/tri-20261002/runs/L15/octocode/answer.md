**Short answer:** `ImmutableSet` builds on an open-addressed, linear-probing hash table. The builder watches for abnormally long probe runs. If it sees one, it abandons that table and falls back to a `java.util.HashSet`-backed implementation, which the code describes as having "built in hash flooding protection". All lines below are in `guava/src/com/google/common/collect/ImmutableSet.java`.

- **Hash spreading:** `insertInHashTable` calls `Hashing.smear(eHash)` on each element's hash code before probing (lines 708–709).
- **Online detection while adding:** the probe loop is `for (int i = i0; i - i0 < maxRunBeforeFallback; i++)` (line 711). If it fills `maxRunBeforeFallback` slots without finding an empty slot or an equal element, it falls out of the loop. Line 724 comments "we fell out of the loop due to a long run; fall back to JDK impl", and line 725 returns `new JdkBackedSetBuilderImpl<E>(this).add(e)`. The comment at lines 821–823 says this catches many exactly matching hash codes, which would otherwise make construction O(n²).
- **Threshold:** `maxRunBeforeFallback(tableSize)` is `MAX_RUN_MULTIPLIER * IntMath.log2(tableSize, ...)` (line 879), and `MAX_RUN_MULTIPLIER = 13` (line 815). The comment at lines 809–810 says it was "determined experimentally" to match the desired false-positive probability.
- **Whole-table check:** `review()` returns `hashFloodingDetected(hashTable) ? new JdkBackedSetBuilderImpl<E>(this) : this` (line 744). `hashFloodingDetected` (lines 835–871) scans the table for runs of non-null slots longer than the threshold. It is O(n) worst case and O(n / log n) on average, because it skips ahead when a slot is empty.
- **Why the second check exists:** the Javadoc at lines 821–826 says the online check can't catch hash codes designed to land in ascending table slots. Construction stays O(n) in that case, but later queries could cost O(n). If `hashFloodingDetected` returns false, "no query can take more than O(log n)".
- **Fallback class:** `JdkBackedSetBuilderImpl` (line 886) copies the deduped elements into a `HashSet` delegate (lines 891–898).
