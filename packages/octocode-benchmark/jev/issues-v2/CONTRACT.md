# Six-issue Terra / Jev comparison — frozen v2

Goal: measure quality of issue triage and proposed bug fixes, with Octocode alone versus Octocode plus the updated Jev reasoning-summary skill.

Cases: R37637=https://github.com/react/react/issues/37637; R37619=https://github.com/react/react/issues/37619; L40592=https://github.com/langchain-ai/langchain/issues/40592; L40590=https://github.com/langchain-ai/langchain/issues/40590; O151639=https://github.com/openclaw/openclaw/issues/151639; O151637=https://github.com/openclaw/openclaw/issues/151637. All are public user-selected cases, not private held-out tests. Do not assume every issue is a bug.

Subjects: twelve fresh gpt-5.6-terra high workers, one per case per arm, fork none. No nested agents or lateral communication. Baseline uses octocode-research with Jev disabled; treatment also reads the updated octocode-jev-logical-if skill and makes one actual Jev call after collecting initial evidence and saving a provisional decision. No arm may read other answers, gold, previous benchmark reports or parent findings. Shared filesystem isolation is instructional, not a security sandbox.

Budget per worker: target eight minutes, maximum 16 Octocode research invocations (five query rows maximum per batch), schema calls separate, two optional local executable checks. No unlogged remote/code research: use run.mjs for Octocode and Jev; setup skill reads are unmetered. One Jev call, pinned jev-1.13.0, retries zero, timeout 10000 ms. Do not replace failed calls. Terminal output size limits are not an excuse to drop necessary continuations. Reassess at 10 research invocations and use remaining budget to verify decisive claims rather than expand scope. Same retrieval and test budget for both arms. Real host tokens unavailable: null, never zero or estimates. Stopwatch starts with run.mjs start and ends with finish, encompassing agent work but not initial spawn/setup. Record actual host spawn/return timestamps separately if available.

Authority: read public issue/source/test evidence using Octocode, write only assigned case directory. Suggest fixes; no upstream messages, PRs, edits to shared repositories or install/build script execution. Optional checks may run self-authored isolated reproductions or reviewed source snippets; record fidelity and exact commands. Do not represent a toy model as actual package runtime. No credentials or private data in requests/logs. Preserve all failures.

Common task: classify issue and supported expected behavior; trace reported version and current source separately; identify mechanism, trigger and divergence; test a plausible alternative; propose the smallest safe fix only if warranted, naming files/symbols and concrete edit or patch; give regression and negative-control tests; distinguish checked facts, proposed fixes and unverified claims. Closing an issue or a comment alone does not prove repair.

Treatment packet: state.mainGoal, goal, reasoning as a concise public reasoning summary (not private chain-of-thought); exact deciding excerpts with source/ref/IDs; assumptions, provisional hunch, competing plausible hypotheses, counterevidence, uncertainty and planned discriminating checks. Include none/insufficient. Use the skill's typed contract. Save decision-before.json before API call; afterward independently check selected source/test evidence and save decision-after.json. A corroboration is not a caused direction change. Do not force an obviously absurd alternative to create apparent agreement.

Return artifacts: answer.md; result.json containing caseId, arm, status, classification, conclusion, confidence, source anchors, fix, verificationRun, verificationMissing, unsupportedClaims, hostInputTokens:null, hostOutputTokens:null; decision-before.json and decision-after.json. Treatment also request.json, actual response receipt, adviceApplied and decisionChanged with explanation. No invented timestamps. Finish only after answer exists. Final return: status, result, up to eight anchors, verification, confidence, next.

Primary KPI: independently judged solution-quality /10: triage/contract 0–2, mechanism with source evidence and alternative check 0–3, concrete safe fix or correct no-fix disposition 0–3, regression/negative-control design and honest verification limits 0–2. Pass >=8 with no major false claim. Runtime findings override plausible prose, with initial grade preserved and correction separate. No-fix cases earn full repair credit only with an evidence-backed disposition and actionable next step. Judge correctness, not verbosity or Jev agreement.

Grading: fresh Terra curator independently researches all six cases and seals expected atoms/source anchors before seeing answers. Parent later supplies anonymized answer pairs only, not workers' decision logs. Curator grades evidence and expected failure modes; parent audits load-bearing anchors and executable checks. Do not reward parent-authored fixes as worker output. Grade unavailable issue/source access as incomplete, not successful negative finding. Record blinding leakage if answers name Jev. Parent separately audits decision attribution from before/request/response/after and actual tools.

Decision rule: exploratory report only. Report per-case and mean paired quality, passes, major false claims, real Jev responses, directions changed, Octocode calls/query rows, Jev tokens, measured task spans and verification fidelity. A higher mean suggests replication, not causal proof. Claim demonstrated gain only for independently verified new/corrected actions that followed nonredundant Jev advice; one run per issue cannot establish product-level superiority. No mid-run policy/rubric/case edits. Pin source refs when discovered; live corpus, shared caches, differing retrieval and model variance remain confounds.

Topology: one independent curator plus paired issue workers (two slots), parent manages frozen harness and later verifies. Six pairs run in order above; no findings shared between pairs. Aggregate caps: 12 workers, 192 research invocations plus curator up to 48 and parent verification up to 30; six paid Jev calls; optional at most 24 worker checks. Stop each worker on cap and retain partial results. No hidden retries or replacements.
