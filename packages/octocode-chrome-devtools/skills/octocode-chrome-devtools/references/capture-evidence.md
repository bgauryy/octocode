# Capture and cite browser evidence

Load when a browser answer needs captured evidence: reuse, filter, classify, read and cite.

Reuse a sufficient preview or saved capture. Otherwise capture once, keeping the complete source, URL and frame, request or node ID. Filter by role/name, URL/method/status or JSON pointer. Search and read exact text with `localSearch` and `localFetch` (the Octocode research tools).

When several passages remain plausible, optional `classification` on search/fetch can select spans. To screen unread resources or images, batch `clasify` references and independent questions about stated or visible facts. Use ordinary readers if unavailable. Verify accessibility, causes, exact relations and counts structurally. Before acting on a classified image or saved ref, confirm live actionability and permission.

Read the deciding evidence, follow required continuations unchanged and resolve unknown scope that could change the answer. Cite each claim beside its source URL or capture path and name unread scope or terminal limits. [Output and saved reports](../output.md) covers findings, steps and gaps.
