Load when finding code by name or meaning, building a ranked prompt context, inspecting one file or symbol, or listing doc links (`search`, `context`, `about`, `files`, `links`).

# Find code in a saved graph

## Find code

| Query | Answer |
|---|---|
| `search <text> [--files\|--symbols] [--all]` | Files and symbols, every declaration included (a sidecar `search-index.json` beside `data.json` adds the ones nothing calls and each comment above a declaration or Python docstring; built on the first search, rebuilt when `data.json` changes). Name matches rank first: `exact` (ignoring case and separators, so `parse_args` finds `parseArgs`) and `prefix` always on top, then `words` (each word or initial starts a name word: `p args`, `gun` → `getUserName`), `substring`, `terms`, `path` (files only). Rows that only hold the query's words come next as `text`, ranked by BM25F over name, enclosing class or function, path, kind, doc comment, names it calls or imports, and signature, so `search where are cycles counted` finds code by what its comments say; name and text ranks fuse by reciprocal rank. `fuzzy` (letters in order) only when nothing holds the text or its words. Test code ranks after production code unless `--tests`. Ties: call sites received, exported, PageRank. Rows carry `match`, `found` (the signals that found it), `words` (the query words it holds), `rank`, `callSites`, and a symbol's span in `loc`. |
| `search <text> --kind K --lang L --role R --path P --exported` | Filters (a comma list each): symbol kind or `file`, file language, file role (`test`, `generated`, `entry`, …), path prefix, exported symbols. A value the graph does not have is an error listing the values it has |
| `search [<text>] --param T --returns T` | Signature filters on the parameter and return type text the engine records (`T` as a whole word: `--returns Node` matches `Node \| undefined`, not `NodeArray`). On a graph that records signatures, a symbol with no written type for the filtered position is left out and counted (`stats.signatureUnknown`); `--unsigned` keeps those after the matches as `signature: unknown`. A graph that records none keeps every symbol as unknown, with a warning. One that does not match drops out; files drop out |
| `search <text> --provider` | The top 20 rows judged by the classification provider configured for `clasify` (`classification.api`; one provider request per row) and fused with the model-free order; moved rows add `provider` to `found`, each judged row carries `provider: { model, score }`. With no provider configured nothing is sent and the answer is the model-free one with a warning. CLI, MCP and the viewer server only |
| `context <file\|symbol...> [--tokens N] [--from K]` | A ranked map for a prompt: files and symbols by PageRank personalized to the named ones (Aider's repo map) over calls weighted by sites × evidence, imports, names taken and declarations, each use also linking back at half weight. The named items first. Rows go in rank order while their estimated tokens (characters / 4) fit `--tokens` (default 1024); `stats` gives `tokens`, `ranked` and `rest`, and `next` holds the `query` (text: `more:`) that continues at `--from` the first row left out. |
| `about <file\|file:line\|symbol>` | One answer around an entity. A file: its `metrics`, `pagerankRank`, `community`, file check, then `dependency` and `dependent` rows (depth 1, strong edges) and `declares` rows by call sites. A symbol: its declaration, then `caller` and `callee` rows. Each row has a `role`. A name that is not a file resolves as a symbol; ambiguity returns candidates. |
| `files <file> [file ...]` | Saved file records and source locations in input order. JSON includes `sourceQueries` for native `localFetch`. Plain paths request the whole source file. A `path:line` requests that line. Multiple lines in one file share one source query. |
| `links [<file>] [--unresolved\|--stale] [--rule <rule>]` | Links beside the code graph, each with its citing `path:line`: docs (`md-link`, `md-path`, `md-cite`, `md-symbol`), manifests and tsconfigs (`manifest`, `tsconfig`) and agents (`agent`, with `confidence` and `proposedBy`). `--unresolved` lists the references that named no single target with `reason` and `candidates`; `--stale` the citations whose code changed under an unchanged doc line. `about` adds a file's or symbol's `documentedBy` rows. [Links](links.md) |

For known source paths, ask `localFetch` directly. Batch several paths in its `queries` array and combine ranges from one file in a single item. To resolve unfamiliar filenames first, use the `sourceQueries` returned by `files`, grouped up to the limit in the local tool schema. Source reads reflect the current checkout. Follow its continuation to retrieve remaining lines.
