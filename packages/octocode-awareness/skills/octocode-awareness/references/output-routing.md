# Output routing

| Information | Destination |
|---|---|
| Current answer or transient explanation | Conversation |
| Decision-changing peer question, blocker, request, or continuation | `message.send` or `message.reply` |
| Shared ownership, dependency, path, or verification state | Existing Work record |
| Verified learning likely to change future work | One scoped Memory record |
| Recoverable file bytes | Host-owned History capture |
| Requested report or export | Its authorized workspace destination |

Do not duplicate one fact across messages, work, memory, and files. Store it in the owner that governs its lifecycle and link to that evidence from other surfaces.
