# Homeostatic loop

Load when operational pressure could change the next action or when reviewing a measurable control loop. Return to the main skill flow afterward.

Agent physiology means sensing computational condition and regulating the conditions for useful reasoning. It is an engineering model, not emotion, personality, or authority.

## Three speeds

| Layer | Owner | Supported behavior |
|---|---|---|
| Reflex | Host admission and installed hooks | Enforce supported prerequisites and exclusive locks; failed edits never create success receipts. |
| Regulation | CLI/library over observed Awareness records | Derive operational state and bounded advice; expose missing sensors and incomplete coverage. |
| Deliberation | Reasoning agent | Explain evidence, select an authorized strategy, and resolve substantive tradeoffs. |

CLI advice does not execute a reflex. A skill cannot install a scheduler or continuously observe host state.

## Observable body

`attend --compact` includes `operational_state` and `regulation`. These describe the selected workspace snapshot, not every computational resource. Full output adds diagnostic organ/drive fields; `--explain-organ` includes the organ reference map even with compact output.

| Condition | Evidence | Bounded response |
|---|---|---|
| Verification debt | Owned observed verification rows and total debt | Inspect the run, execute its declared check, record the actual outcome. |
| Coordination pressure | Observed overlap and lock rows for selected files | Inspect the relevant path; ordinary overlap stays advisory. |
| Reference weakness | Selected memory references and trust warnings | Recheck current source; file presence alone does not prove consistency. |
| Packet coverage | Counts, selected rows, and omissions | Retrieve only missing details needed for the decision. |
| Host resource condition | Context, tool history, budget, and worker telemetry only if the host measures them | Use the owning host's control; unknown is not healthy or unhealthy. |

Native `attend` includes context/tool measurements and persisted core retry/compaction receipts. Changed context invalidates occupancy; tool outcomes use a fixed window. Standalone CLI cannot observe the runtime.

Task counts do not measure progress; selected memory hits do not measure evidence coverage. No fabricated entropy, error pressure, rollback forecast, or cognitive-yield score. Reflection and cleanup are not measurements of information gained per token.

## Feedback

```text
SENSE -> ATTEND -> CHOOSE/DECLARE -> ACT -> VERIFY -> REMEASURE
```

Compare the observed condition before and after one bounded intervention. Keep it only when the target improves without violating another guard. Refresh after a material state change, not on every reasoning step. If no actionable shared pressure remains, continue authorized work rather than following an attend-to-attend loop.

Preserve omissions, errors, pending work, and unresolved signals. Never infer success from expiry, cleanup, a peer claim, or a recommendation. Store only reusable verified learning; preview cleanup before mutation. Regulation cannot authorize policy edits or silent skill changes.

## Independent review

Use a real second agent for a hard explanation, risky decision, or recurring weakness when a direct check is insufficient. `reflect record --duo` returns prompts but launches no subagent. The review agent stays read-only and creates no claims or durable rows.

Frame one question with acceptance criteria and source/row IDs. Ask for an independent restatement, challenge, and falsification; preserve dissent and run a decisive source/test check. Agreement is not verification. Capture only verified reusable synthesis through [learning loop](learning-loop.md).
