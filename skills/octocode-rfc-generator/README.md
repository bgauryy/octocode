# Octocode RFC Generator

Write one clear RFC containing the decision, design, alternatives, risks, implementation plan, validation, and references. Keeping these together makes review easier and prevents the plan from drifting away from its rationale.

Use plain, precise language and evidence-backed claims. Deliver the RFC without probe logs or generated metadata. HTML export is available when explicitly requested.

Start with [SKILL.md](SKILL.md). [output.md](output.md) defines the structure and language.
