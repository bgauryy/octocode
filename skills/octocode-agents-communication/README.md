# Octocode Agents Communication

Coordinate local agents across sessions, hosts, or worktrees with peers, message parts, explicit request outcomes, immutable evidence documents, path leases, and delivery recovery. Uses A2A concepts locally; it does not implement A2A's remote protocol.

Start with [Choose the interface](SKILL.md#choose-the-interface): connected MCP supplies its own instructions; the CLI route is under [Run the CLI](SKILL.md#run-the-cli) and requirements under [Set up and recover](SKILL.md#set-up-and-recover). The published package holds the runtime, operating guide, setup guide and command contracts.

Results and saved reports follow [output.md](output.md).
