# Octocode Subagent

Decide how to run substantial work: solo, batched, delegated to tool-using workers, handed to a remote A2A peer, or offloaded to a local Ollama model. Triggers, flow, and rules live in `SKILL.md`.

Install: `npx -y octocode skill install octocode-subagent`. Maintainer check: `node scripts/eval-contract.mjs`, then the `octocode-skills` review of this folder.
