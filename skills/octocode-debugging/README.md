# Octocode Debugging

Use [the skill](SKILL.md) to investigate runtime behavior or make sense of evidence you already have. A failing input, a stack trace, a live service or a saved profile can each be a starting point.

The [debugger techniques](references/debugger-techniques.md) cover conditional stops, watchpoints, event breakpoints, logpoints, dumps and replay. The [optional references](SKILL.md#optional-references) include profiling and runtime-specific commands. The bundled Node helpers require Node 22 or later. The native capture helper uses macOS sample or Linux perf with access to the target process. For a saved document or visual, see [output options](output.md).
