# Octocode Chrome DevTools

Use this skill for interactive pages, logged-in state, and browser diagnostics. Start at [SKILL.md](SKILL.md); [output.md](output.md) defines the response and saved-report format.

Install the complete folder in your agent's skill directory so its references and report renderer stay beside `SKILL.md`. The `skill` command of `@octocodeai/octocode-chrome-devtools` serves package operating guides; it does not register this Agent Skill.
