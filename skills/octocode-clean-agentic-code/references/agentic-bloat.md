# Agent Bloat

Load when agent-authored code adds weight without behavior: checker suppressions, speculative abstraction, churn, scratch scripts, attribution comments, literal or parameter noise. A suppressed dead-code lint hides the candidates this skill hunts. Rows preserve behavior once their bar holds; send "Report" rows to `references/agentic-correctness.md`.

## Checker suppressions

Signals: `#[allow]`, `eslint-disable`, `@ts-ignore`, `# noqa`, `# type: ignore`, `//nolint`, `as any`. Exempt generated files, vendored code, test fixtures, and third-party corpora. A suppression a generator writes into its output belongs to the output.

| Signal | Keep when | Otherwise |
|---|---|---|
| `as any`, `: any`, `as unknown as`, `@ts-ignore`, `@ts-nocheck`, `# type: ignore`, `cast(Any, …)` | generated file, or the line says why the type cannot be expressed | Use the real type when the typecheck passes; report a fix that changes runtime code |
| Non-null `!` or `as T` on a nullable value | an adjacent invariant proves presence | Report: removal changes the null path |
| `eslint-disable`, `# noqa`, `//nolint`, `#[allow(…)]` | one line or item, with a reason | Remove when the linter passes without it; a file- or crate-wide suppression needs a reason per lint |
| Suppressed `dead_code`, `unused`, `unreachable` | structural cause (one helper module compiled into many test binaries), reason written | Delete the dead item or the code that makes the arm unreachable. A reason naming a removed counterpart ("parity with the old X") is residue |
| Suppressed complexity lint (`too_many_arguments`, cognitive or type complexity) | always, until a structural change | Inventory it for `references/structure.md`; never fix it in a batch. A raised config threshold only moves the suppression |
| Safety lint (`expect_used`, `panic`, `unwrap_used`) suppressed in production | a comment states why the call cannot fail | Report: error handling changes behavior |

Sweep (the checker finds stale suppressions):
1. Make each first-party suppression self-reporting: `#[allow]` → `#[expect]` (`unfulfilled_lint_expectations`); `@ts-ignore` → `@ts-expect-error`; ESLint `--report-unused-disable-directives`; mypy `warn_unused_ignores`; ruff `RUF100`; golangci-lint `nolintlint`.
2. Run the checker under every configuration the repo builds (feature sets, targets, test and non-test).
3. Delete each suppression no configuration needs. Otherwise fix the local cause: feature-gated value in the literal, map instead of a struct with an unread field, write out the arm a macro made unreachable, drop an import-path hack the runtime provides.
4. Move blanket test allowances to tool config (`allow-expect-in-tests`, `allow-panic-in-tests`, an ESLint override for test globs).
5. Keep the self-reporting form only where every configuration fulfills it; revert the rest. Each survivor carries a reason (`reason = "…"` or a line comment).

Changing the guarded code may change behavior.

## Speculative generality

| Signal | Evidence bar |
|---|---|
| Interface, ABC, or Protocol with one implementation | No implementor via public exports, plugins, or test substitutes |
| Factory, registry, or strategy table with one entry | No config or plugin path registers another |
| Option every caller passes with the same value | All callers listed with `lspSearch`; symbol not exported |
| Generic with one instantiation; wrapper that only forwards | No public contract names it |
| Unused parameter on an internal signature | Not exported; no interface or callback slot requires it |

## Churn and leftovers

| Signal | Remove when |
|---|---|
| Hunks that only change type hints, decorators, or annotations on untouched functions | No runtime reader uses them (pydantic, dataclasses, FastAPI, attrs, DI containers, reflection); else report |
| Unreferenced `fix_*`, `migrate_*`, `debug_*`, `scratch*`, `tmp_*` scripts, or `test_*` files outside test roots | No script, CI job, or doc runs them |
| AI-attribution comments (`generated by`, `written with`, `assisted by` + model or tool name), not in data, fixtures, or transcripts | No disclosure or license policy requires them |
| One string literal repeated across a module | Every copy means the same thing; extract one constant |
| New `console.log`, `print(`, `dbg!`, `println!` in non-CLI code | Report: output is observable |
| `sleep(` or a retry loop around a failing call | Report: it hides the root cause |
