# Decision Residue

Load when code, comments, skills, or docs record how a decision was made instead of the decision. Test: must a reader act on it? Keep the decision; its evidence belongs in the commit, the PR, or one declared evidence owner.

| Type | Example | Remove when |
|---|---|---|
| Decision narration | `// chose a Map here after benchmarking both`, `// verified: no other callers` | Always |
| Pasted probe output | caller or hit counts, tree listings, tool transcripts | Always |
| Provenance trail | "Sources consulted", research trails, evidence tables, confidence scores, ratings, install counts | The artifact is not the declared evidence owner |
| Process metadata | round or attempt labels, session and run IDs, reviewer names, ticket chatter (AI attribution: `references/agentic-bloat.md`) | Always in a shipped artifact |
| Dated claims | "as of <date>", "currently", "recently added", version stamps in prose | The doc is evergreen and no owner refreshes the date |
| Stale-prone counts | counts of files, references, classes, packages, or tests in prose | No check reads the number |
| Restated facts | one rule in two files; a summary repeating its reference | Keep one owner |

Number test: does a check fail if the number is wrong? Yes: it is a contract; keep it and name the check. No: rewrite without it. A measured figure stays only with an owner and a refresh path.

Keep: a threshold, limit, or version a script, test, lint rule, or manifest reads; evidence in its single declared owner; provenance a license, security review, or compliance record requires; a dated finding in a dated snapshot; routed load-on-demand evidence (a copy in a lobby, README, or comment is residue).

Detect and excise:
1. Text-search `Sources consulted`, `Research trail`, `as of`, `verified`, `confirmed`, `Based on`, `per the`, `generated by`, `round`, `attempt`, and bare years and percentages in prose.
2. Read each hit in place: it can be a live constraint.
3. Search the repo for the literal number or key a check may consume.
4. Confirm no doc index declares the provenance section as the file's concept.
5. Delete in a normal batch: behavior is preserved. Next: `references/cleanup-playbook.md` EXCISE.
